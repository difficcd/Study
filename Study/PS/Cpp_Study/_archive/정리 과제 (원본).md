### **3 )  동적 할당 / 반환**

new 와 delete로 동적 할당하는 방법 익히기 

정적인 변수들과 달리, 동적인 변수는 실행중에 운영체제에게 할당받음

delete 사용의 중요성

- char *p  = new char[1024] 처럼 동적으로 할당한 포인터변수를  n=’a’   p = &n 처럼 바꾸면?
    
    기존의 new로 선언된 char[1024]의 용량 1024 를 사용하지 않음 : 메모리누수
    
- char *p 를 여러 번 p = new char[1024] 처럼 동적할당하면?
    
    할당 시마다 공간이 생기고 delete 되지 않기에 메모리 누수 발생
    

- 잡다한 규칙 (#중요)
    
    new,delete   new[] delete[]  짝 맞춰서 사용 (new 선언시의 변수형식으로)
    
    NULL 포인터인 경우에도 delete해도 괜찮지만, 아무 일도 하지 않음(NULL이라)
    
    ! 이떄, p 가 new 로 할당받은 동적포인터가 아니더라도 *p=NULL이면 delete p 가능
    
    동적으로 할당받지 않았거나 delete를 이미 했는데 또 하면 실행시간 오류 발생
    
    배열로 선언된 동적할당 포인터 그냥 delete하면 비정상 반환
    

- 코드로 이해
    
    ```cpp
    #include <iostream>
    using namespace std;
    
    //main
    int main(){
      int *pt = new int(0); // 타입 포인터이름 = new 타입
      // (0)은 초기값으로, 0으로 초기화된 int 타입 뜻함
      // 배열은 초기화 불가
      
      int size;  int sum = 0;
      cin >> size;     
      
      int *p = new int[size]; 
      // size 이후 선언되는 배열형식 포인터변수
    
      if(!p || !pt) return 0; // 메모리할당 여부 ck
      
      for(int i=0; i<size; i++){
        cin >> pt[i];
        cin >> p[i];
      }
        
      for(int i=0; i<size; i++){
        cout << pt[i] << " "; // 1 2 3 출력 (3 11 22 33 입력)
        sum += p[i]; // sum이니 6 출력
      }
      cout << "\n" << sum << endl;
      
      delete pt; // delete 포인터이름 
      pt = NULL; 
      // 포인터변수가 없어지는건 아니므로, NULL 지정이 안전
      
    }
    
    ```

### **5 ) 멤버함수의 this 포인터 OK**

this ) 멤버함수를 소유한 객체를 가리키는 포인터

클래스 멤버함수 내에서만! 사용하고, 컴파일러가 선언한 변수다 (묵시적 삽입선언)

- this 포인터의 제약 사항과 처리방법
    
    1 ) 멤버 함수가 아닌 함수에서는, this 사용 불가 (정의를 생각해보면 당연하다)
    
    2 ) static 멤버함수에서는 this 가 사용 불가하다 
    
    ⇒ 객체 생기기 전에 static 함수 호출이 존재할 수 있기 때문
    
    (static 멤버 함수는 클래스이름::static 함수 이름으로 객체없이 호출가능함)
    
    ---
    
    개발자가 Void **setA**(int x) { this→a = x; } 라는 함수를 작성했으면,
    
    컴파일러는 Void **setA**(Sample* this, int x) {…} 로 변환하여 처리한다
    
    >> 묵시적으로 삽입된 매개 변수이기 때문에 처리 시에는 완전히 처리
    
    >> class Sample 이라 할 때 Sample ob; ob.**setA**(5) 하면 ob.**setA**(&ob,5); 로.
    
    (ob 주소가 this 매개변수에 전달되는 것. 암묵적인 처리) 호출시 해당객체 주소 넘겨줌
    
- 코드로 이해
    
    ```cpp
    #include <iostream>
    using namespace std;
    
    //class
    class Circle{ 
    private:
      int radius;
    public:
      Circle() { radius = 5; }
      Circle(int r) { radius = r; }
      ~Circle();
    
      void setRadius(int radius)  { this->radius = radius; } 
      //this 포인터 사용
      // 매개변수 이름과 바꿀 변수(멤버변수) 이름이 같을 때 사용가능!
    
      Circle* getAdd() {return this;} 
      // 객체타입=클래스이름 + 리턴 포인터*
      // 객체 자기 자신의 주소를 리턴할 수 있어, 간편하다. &객체와 동일한 주소 반환
    
      double getArea()  { return 3*radius*radius;} 
    };
    
    Circle::~Circle(){
      cout << "소멸자 r = " << radius << endl;
    }
    
    //main
    int main(){
      Circle c1, c2;
      
      c1.setRadius(4); // 여기서 this 로 radius 값 갱신
      c2.setRadius(10);
      cout << c1.getArea() << "   주소 : " << &c1 << endl ; // 4 * 4 * 3
      cout << c2.getArea() << "   주소 : " << &c2 << endl ; // 10 * 10 * 3
      cout << c2.getAdd() << endl ; // c2 this 포인터 = &c2 동일하고, c1과 상이
      
      // &c1 은 c1객체의 this 포인터, &c2 는 c2객체의 this포인터와 같다
      // 두 객체의 this 포인터는 서로 다름을 알 수 있다
    }
    
    ```

### 1 ) 객체 전달과 참조 : 객체 매개변수 사용

**(1) call by value** 

→ 생성자 호출 X 소멸자 호출 O

### 2 ) 복사 생성자

**(1) C++ 의 얕은 복사와 깊은 복사**

객체 복사 시 멤버를 1:1 복사

얕은 복사 - 멤버 변수에 동적메모리 할당된 경우, 사본: 원본과의 메모리 공유 문제

깊은 복사 - 멤버 변수에 동적메모리 할당된 경우, 사본은 별도로 동적할당. 내용만 복사

완전한 형태의 복사는 깊은 복사 (사본/원본의 메모리 공유가 없어야)

**(2) 객체 간 초기화/대입**

같은 클래스 객체 간 초기화/대입 가능

객체 간의 초기화 = 복사생성자  (같은 클래스의 다른 객체와 같은 값 갖도록 1대1로 초기화)

객체 간의 대입 = 대입연산자 (같은 클래스의 다른 객체의 값을 1대1로 대입)

**(3) 복사 생성자**

객체 복사 생성시 호출되는 특별 생성자, 같은 클래스 객체 이용해서 초기화하는 생성자

형태는 클래스명(객체 참조 매개변수) 꼴 → ex) Circle(Circle* c) {…}

>> ++a 는 ++(a)     a++ 는 ++(a,0) 으로 변환하여 두 연산자를 구분함 (0은 의미 x)

    ```cpp
    #include <iostream>
    using namespace std;
    
    class Power { // 에너지를 표현하는 파워 클래스
    public:
      int kick;  // 발로 차는 힘
      int punch; // 주먹으로 치는 힘
      Power(int kick = 0, int punch = 0) { //생성자
        this->kick = kick;
        this->punch = punch;
      }
    
        Power operator++() { // 매개변수X :: 전위 연산자
         kick++; punch++;
         return *this; // 변경된객체자신(객체a) 리턴
        }
    
        Power operator++(int x) { // 매개변수O :: 후위 연산자
        // friend 로 선언하려면 매개변수로 객체 받아야함! (접근방법이 없음)
         Power tmp = *this; // 증가 이전 객체상태 
         kick++; punch++;
         return tmp; // 변경된객체자신(객체a) 리턴
        }
    
      void show() { cout << "kick = " << kick << " " << "punch = " << punch << endl; }
    
    };
    
    int main() {
      Power a(3, 5), b(4, 6);
    
      a.show(); b.show();
      ++a; a.show(); // 전위 test
    
      cout << "b++ 값 : " << b++.kick << endl; // 후위 = 증가 전, 4
        // 편의상 public 으로 변수선언, 바로 접근
      cout << "b++ 값 : " << b.kick << endl; // 증가 후, 5
        
    }
    
    ```
    
- **코드 이해 (전위 후위 ++ friend : 레퍼런스 사용 )**
    
    ```cpp
    #include <iostream>
    using namespace std;
    
    class Power { // 에너지를 표현하는 파워 클래스
    private:
      int kick;  // 발로 차는 힘
      int punch; // 주먹으로 치는 힘
    
    public:
      Power(int kick = 0, int punch = 0) { //생성자
        this->kick = kick;
        this->punch = punch;
      }
    
     friend Power& operator++(Power& op); // 전위 ++
     friend Power operator++(Power& op, int x);  // 후위 ++
    
      void show() { cout << "kick = " << kick << " " << "punch = " << punch << endl; }
    };
    
    Power& operator++(Power& op) { // 전위++  
        // 레퍼런스 리턴값으로 객체 원본값 변경
        op.kick++; op.punch++; 
        return op; 
        // 연산결과리턴 (++a 에서는 필요없으나 b = ++a 에서 필요)
        // 함수정의 자체를 리턴값있게 (void아님) 했기에 리턴 꼭필요 
        // return 0 같이 이해
    }
    
     Power operator++(Power& op, int x) { // 후위++ 
         // 레퍼런스 리턴값으로 객체 원본값 변경
        Power tmp= op; // 변경하기전의op 상태저장
        op.kick++; op.punch++;  
         return tmp; // 변경이전의op 리턴
    }
    
    int main() {
      Power a(3,5), b;
     b = ++a; a.show(); b.show();  // a 증가 후의 값 4 6  4 6 
     b = a++; a.show(); b.show();  
    // a 는 증가된 값 (2번 증가 완료)  b는 증가전 a값이니 4 6 그대로 나옴
    }
    
    ```

- **(3) 파생 클래스 생성자 /소멸자**
    
    파생 클래스 객체 생성시 = 부모 & 해당 클래스 생성자 둘 다 실행 (기본 → 파생 순서)
    
    기본 클래스 디폴트 생성자는 암시적으로 호출된다 (파생의 생성자가 기본 생성자 호출)
    
    이때 부모가 F(int x) 면 자식도 F’(int x) 처럼 매개변수 등이 꼭 있어줘야 함 (자식→부모호출)
    
    다만, 자식이 F’(int x) 이고 부모가 F() 인 경우는 괜찮다 (인자O 생성자가 디폴트 생성자 호출)
    
    파생 클래스 생성자는 묵시적으로 부모의 기본 생성자를 호출하지만,
    
    F’(intx) : F(x+3) { } 처럼 특정 클래스를 명시적으로 호출할 수도 있다.
    
    **이러한 구조여서, 부모 클래스의 디폴트 생성자는 그냥 거의 필수로 써줘야 한다
    
    파생 클래스 객체 소멸시 = 파생 → 기본 순서

        using namespace std;
        
        const int DEFAULT_SIZE = 100;
        
        template <class T = int>
        class Stack {
        protected:
        	int m_size; int m_top; T* m_buffer;
        public:
        	Stack(int size = DEFAULT_SIZE);
        	~Stack(); void Push(T value); T Pop();
        };
        
        //생성자
        template <class T>
        Stack<T>::Stack(int size) {
        	m_size = size;	m_top = -1;
        	m_buffer = new T[m_size];
        }
        
        //소멸자
        template <class T>
        Stack<T>::~Stack() { delete[] m_buffer; }
        
        //push 함수 구현
        template <class T>
        void Stack<T>::Push(T value) {
        	if (m_top >= m_size - 1) {
        		cerr << "Stack Overflow!" << endl;
        		return;
        	}
        	m_buffer[++m_top] = value;
        }
        
        //pop 함수 구현
        template <class T>
        T Stack<T>::Pop() {
        	if (m_top < 0) {
        		cerr << "Stack Underflow!" << endl;
        		return T();  // 기본 생성된 값 반환
        	}
        	return m_buffer[m_top--];
        }
        
        int main() {
        	Stack<int> iStack;
        	Stack<double> dStack;
        
        	iStack.Push(3);
        	int n = iStack.Pop();
        
        	dStack.Push(3.5);
        	double d = dStack.Pop();
        
        	cout << "int pop: " << n << ", double pop: " << d << endl;
        
        	return 0;
        }

            #include <iostream>
            using namespace std;
            
            template <typename T>
            T* remove(T src[], int sizeSrc, T minus[], int sizeMinus, int& retSize) {
            
                // x 몇개 y 몇개 (제거해야하는 개수)
            
                T* temp = new T[sizeSrc];
                int count = 0;
            
                for (int i = 0; i < sizeSrc; i++) {
                    bool found = false;
                    for (int j = 0; j < sizeMinus; j++) {
                        if (src[i] == minus[j]) {
                            found = true;
                            break;
                        }
                    }
                    if (!found)
                        temp[count++] = src[i];
                }
            
                retSize = count;
            
                if (retSize == 0) {
                    delete[] temp;
                    return nullptr;
                }
            
                T* result = new T[retSize];
                for (int i = 0; i < retSize; i++)
                    result[i] = temp[i];
            
                delete[] temp;
                return result;
            }
            
            int main() {
                // remove() 함수를 int로 구체화하는 경우
                cout << "정수 배열 {1,2,3,4}에서 정수 배열 {-3,5,10,1,2,3}을 뺍니다" << endl;
                int x[] = { 1, 2, 3, 4 };
                int y[] = { -3, 5, 10, 1, 2, 3 };
                int retSize;
            
                int* p = remove(x, 4, y, 6, retSize);
                if (retSize == 0) {
                    cout << "모두 제거되어 리턴하는 배열이 없습니다." << endl;
                }
                else {
                    for (int i = 0; i < retSize; i++)
                        cout << p[i] << ' ';
                    cout << endl;
                    delete[] p;

                double dx[] = { 1.1, 2.2, 3.3, 4.4 };
                double dy[] = { 3.3, 5.5 };
                double* dp = remove(dx, 4, dy, 2, retSize);

            mem = new int[capacity];
        }
        ~BaseArray() { delete[] mem; }

        int get(int index) { return mem[index]; }
        int getCapacity() { return capacity; }
    };

    private:
        int front, rear, count;
    public:
        MyQueue(int capa = 100) : BaseArray(capa), front(0), rear(0), count(0) {}
    
        void enqueue(int n) { put(rear, n); rear++; count++;}
        int dequeue() { int val = get(front); front++; count--; return val;}
    
        int length() { return count; }
        int capacity() { return getCapacity(); }
    };

### #OOP개념 : 용어정리 (객지프 C++ 01)

클래스 = 객체를 정의하는 틀 (변수 + 프로시저(함수))

           특성 >> 캡슐화, 상속, 다형성

객체 = 클래스형에 의해 만들어진 실사용변수 

멤버변수 = 객체 내부의 변수 (객체 내부정보 저장)

멤버함수 = 객체 내부의 프로시저 (객체가 수행가능한 행위 기술)

*생성자 = 객체 초기화에 사용하는 멤버함수

keyword : 클래스, 객체, 멤버변수, 멤버함수, 생성자

keyword : 캡슐화, 상속, 다형성, 제네릭 프로그래밍 가능

C++에서는 iostream이 기본적인 입출력 라이브러리

std::cout << “내용\n”;    // C++에서의 출력객체. 자료형 자동조정

```cpp
#include <iostream>
#include <vector>
using namespace std;

template <typename T> 
// 제네릭 프로그래밍 (템플릿) : T를 다양한타입으로 사용가능
class Animal { // 클래스 정의
private:
    T age; // 멤버변수 (캡슐화: private 접근 지정자 사용)
public:
    Animal(T a) : age(a) {} // 생성자
    virtual void sound() { // 멤버함수 (다형성: 가상 함수)
        cout << "Animal sound" << endl;
    }
    T getAge() { return age; } // 멤버함수
};

// 상속 (부모 클래스 Animal, 자식 클래스 Dog : 클래스확장)
class Dog : public Animal<int> {
public:
    Dog(int a) : Animal(a) {}
    void sound() override { // 다형성: 오버라이딩
        cout << "Woof!" << endl;  } // 
};

int main() {
    Dog myDog(3); // 객체 생성
    cout << "Dog's age: " << myDog.getAge() << endl;
    myDog.sound(); // 멤버함수 호출
    return 0;
}
```

위 코드의 실행결과 

>> Dog’s age = 3

>> Woof!
