# 클래스와 객체 기초

**클래스 = 설계도, 객체 = 그 설계도로 찍어낸 실체(인스턴스).** OOP 의 출발점.

- **객체(= 인스턴스)** : 상태 + 행동을 가지는 실제 사용 변수 → **메모리에 생성**됨
    - 클래스의 모양을 그대로 가지고 태어남
    - 멤버 변수 + 멤버 함수로 구성. 객체들은 **서로 별도의 공간**에 생성
- **클래스** : 사용자 정의 자료형, 객체를 찍어내기 위한 **설계도**
    - 클래스 자체는 객체가 아님(실체 X). 멤버 변수·멤버 함수를 **선언**만 함
    - 한 클래스로 여러 객체 생성 가능
- **멤버 변수** : 클래스의 멤버인 변수 (이름에 `m_`, `_` 접두사 관례)
- **멤버 함수** : 클래스의 멤버인 함수 → 클래스 내 모든 멤버를 객체 이름 없이 직접 사용

```cpp
class TV {
    bool on;
    int channel, volume;
public:
    void powerOn() {}
};   // 클래스 끝에는 반드시 세미콜론 ;
```

# string과 vector 클래스

C-스트링 대신 C++ 이 제공하는 **표준 클래스** 두 가지. 크기 걱정 없이 편하게 쓸 수 있음.

## string 클래스

C++ 표준 라이브러리 `<string>` 헤더에 선언. 다양한 문자열 연산(복사·비교·길이 등)을 연산자/멤버함수로 제공.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string str = "ab";        // 가변 크기 문자열
    str.append("cd");         // "abcd"  (.append 로 뒤에 추가)

    string dest = str;        // 복사 — string 끼리는 대입/비교가 쉬움
    int len = str.size();     // 길이

    string test = "#";
    test += dest;             // "#abcd"

    if (str == "abcd")        // == 로 직접 비교
        cout << "result";
    cout << str.find("cd");   // 부분 문자열 위치 찾기
}
```

- 연산자로 문자열 결합, `==` `!=` 로 비교 가능
- "문자열 / 스트링 / string 객체" 등으로 혼용해서 부름
- 주요 멤버 함수는 교재 17p 참조

## vector 클래스

**가변 길이 배열(동적 배열)** 을 구현한 제네릭 클래스. 길이를 미리 고민할 필요 없음.

- template 클래스라 **타입 무관**하게 다루기 쉬움
- 원소 저장·삭제·검색 등 다양한 멤버 함수 지원
- 원소는 인덱스로 **연속된 메모리**에 저장 → 공간 효율 좋고 `operator[]` 로 임의 접근 빠름
- **끝에서의** 삽입/삭제가 특히 빠름
- 주요 멤버/연산자는 교재 19p 참조

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(1);  v.push_back(2);

    int s = v.size();       // 원소 개수
    int c = v.capacity();   // 용량

    v.at(1) = 4;            // 안전한 접근 (범위 검사)
    int n = v.at(1);
    v[0] = 10;             // 빠른 접근 (범위 검사 X)
    int m = v[1];
}
```

# 클래스 정의와 사용

클래스는 **선언부(무엇이 있는가)** 와 **구현부(어떻게 동작하는가)** 로 나눠 작성하는 게 기본.

- `class` 키워드로 정의
- **접근 지정자** : `private` / `protected` / `public` (디폴트 `private`) → 정보 은닉·캡슐화
- **선언부** : 멤버 변수·함수를 선언. 변수는 선언 내에서 초기화 불가, 함수는 원형만
- **구현부** : 모든 멤버 함수를 구현 (선언과 동시에도 가능)

```cpp
class Circle {          // 선언부
public:
    int radius;
    double getArea();   // 원형만 선언
};

double Circle::getArea() {   // 구현부 (:: 범위 지정)
    return 3.14 * radius * radius;
}
```

> [!note] 선언부에서 바로 구현하면 inline
> ```cpp
> class Circle {
> private:
>     int radius;
> public:
>     double getArea() {          // 선언부에서 바로 구현
>         return 3.14 * radius * radius;
>     }   // → inline 함수로 처리됨 (코드 복사)
> };
> ```

### 객체 생성과 멤버 접근

- 객체를 생성하면 **메모리가 먼저 할당**되고, 값 할당은 그 뒤 → 값 할당이 간편
- **일반 객체** → `.` 연산자로 접근
- **동적 객체** (객체 포인터) → `->` 연산자로 접근

```cpp
Circle c1;                    // 일반 객체
c1.radius = 2;

Circle* c2 = new Circle;      // 동적 객체 (포인터)
c2->radius = 2;
```

- 멤버 함수를 **밖에서** 호출하려면 객체 이름 지정 필요 (`c.getArea()`)
- 멤버 함수 **안에서** 같은 클래스 멤버 접근 시엔 객체 이름 불필요
- 멤버 함수 안에서는 접근 지정자와 상관없이 클래스 모든 멤버 사용 가능 (캡슐화 내부 단계이므로)

# 생성자와 소멸자

- **생성자** : 객체 생성 시 자동 호출되는 멤버 함수 → **초기화** 담당. `클래스이름()` 형식
- **소멸자** : 객체 소멸 시 자동 호출 → **정리(마무리)** 담당. `~클래스이름()` 형식
    - 루프를 빠져나가는 등 객체가 사라질 때 정리가 필요

## 생성자·소멸자 공통 특징

- 모든 클래스에 생성자·소멸자가 **반드시 존재** (안 만들면 자동 생성)
- **리턴 값이 없음** (`void` 도 안 됨)
- 객체 생성 시 생성자 / 소멸 시 소멸자가 **자동 호출**
- **생성자는 중복 가능, 소멸자는 중복 불가**

## 생성자 자세히

- 객체 생성 시 **오직 한 번** 자동 호출, 임의 호출 불가. 각 객체마다 실행
- **중복 가능** : 한 클래스에 여러 개 두되, 실행은 형식에 맞는 **하나만**
- **디폴트 생성자** : 사용자가 안 만들면 자동 호출용 빈 생성자가 생김 (`Circle` → `Circle()`)

```cpp
class Circle {
    int radius;
    Circle();        // 매개변수 없는 생성자
    Circle(int r);   // 매개변수 있는 생성자 (리턴타입 명기 X)
};

Circle::Circle()      { radius = 1; }
Circle::Circle(int r) { radius = r; }

Circle donut;         // 매개변수 없는 생성자 호출
Circle pizza(30);     // 매개변수 있는 생성자 호출
```

생성자 중복의 대표 사례가 바로 `string`:

```cpp
class string {
public:
    string();              // 빈 문자열
    string(string& str);   // str 을 복사한 새 객체
    string(char* s);       // '\0' 로 끝나는 C-스트링으로 생성
};

string str;                              // 빈 문자열
string address("청주시 서원구 충대로1");
string copyAddress(address);             // address 를 복사
```

> [!warning] 인자 있는 생성자를 만들면 디폴트 생성자가 사라진다
> 사용자가 생성자를 **하나라도** 만들면 컴파일러는 디폴트(인자 없는) 생성자를 자동 생성하지 않는다.
> 인자 있는 생성자만 만들었는데 `Circle arr[]` 처럼 인자 없는 생성자가 필요한 경우가 많으므로,
> **인자 있는 생성자를 만들 땐 인자 없는 생성자도 함께** 만들어 주는 게 안전.

**디폴트 인자로 중복 간소화** — 매개변수 없는 경우까지 하나로 커버:

```cpp
class Circle {
public:
    Circle(int r = 1) { radius = r; }
    // 디폴트 인자 → 인자 있음/없음 둘 다 처리
    // 단, Circle() 과 Circle(int) 를 따로 둔 버전과 함께 쓸 수는 없음
};
```

## 소멸자 자세히

- 객체가 소멸되는 시점(메모리 소멸 직전)에 **자동 호출**, 한 번만, 임의 호출 불가
- **마무리 작업** 담당 : 동적 할당 메모리 해제 / 파일 저장·닫기 / 네트워크 닫기 등
- 리턴타입 X, **매개변수 X → 오버로딩 불가** (오직 하나)
- 선언 안 하면 컴파일러가 디폴트 소멸자 생성 (아무것도 안 하고 리턴)

```cpp
class Circle {
public:
    int radius;
    Circle();
    Circle(int r);
    ~Circle();          // 소멸자
    double getArea();
};

Circle::Circle()      { radius = 1; cout << "반지름 " << radius << " 원 생성" << endl; }
Circle::Circle(int r) { radius = r; cout << "반지름 " << radius << " 원 생성" << endl; }
Circle::~Circle()     { cout << "반지름 " << radius << " 원 소멸" << endl; }
```

## 생성자·소멸자 실행 순서

교재 17~19p 참조. **선언 위치**에 따라 생성/소멸 시점이 갈림.

| 객체 종류 | 생성 시점 | 소멸 시점 |
|-----------|-----------|-----------|
| **지역 객체** (함수 내) | 호출되는 순간, 선언 순서대로 | 함수 종료 시, **생성의 역순** |
| **전역 객체** (함수 밖) | 프로그램 시작 시, 선언 순서대로 | 프로그램 종료 시, **생성의 역순** |

- **동적 생성 객체** (`new`)
    - `new` 하는 순간 생성 / `delete` 할 때 소멸
    - `new` ↔ `malloc`, `delete` ↔ `free` 에 대응
    - `int* ptr = new int[n];` (n = 할당할 int 개수)

## 객체 간 초기화 / 대입

같은 클래스 객체끼리 서로 초기화·대입 가능.

- **초기화 = 복사 생성자** : 다른 객체와 같은 값을 갖도록, 멤버 변수를 1:1 초기화
- **대입 = 대입 연산자** : 다른 객체의 값을 1:1 대입

```cpp
Stack s1(5);
Stack s2 = s1;   // 초기화 → 복사 생성자
Stack s3;
s3 = s1;         // 대입   → 대입 연산자
```

> [!tip] 디폴트로 자동 생성되는 함수 4종
> 디폴트 **생성자 / 소멸자 / 복사 생성자 / 대입 연산자**.
> 그리고 **주기만 하는 값에는 무조건 `const`** 를 붙이자 (손상 방지).

# 분할 컴파일

바람직한 C++ 프로그램은 **클래스를 헤더(.h) / 소스(.cpp) 로 분리**해서 작성. 파이썬의 `import ~ from ~` 과 비슷한 느낌 — 협업·큰 프로젝트에 유용.

- **선언부** → `클래스이름.h` 에 저장
- **구현부**(멤버 함수 구현) → `클래스이름.cpp` 에 저장
- `main()` 등 전역 함수·변수 → 별도 `.cpp` 에
- 필요한 곳에서 클래스가 선언된 헤더를 `include`

![[image.png]]

- `private` 멤버는 밖에서 못 보므로, **접근자(getter)** 를 구현해 접근 (`Circle.cpp` 참조)
    - `getRadius()` 가 `radius` 를 return → 이를 통해 접근
- `main.cpp` = 응용 프로그램, `Circle.cpp` = 구현부

> [!warning] 헤더 중복 include 문제 → include guard
> `#include` 는 **텍스트 복사/붙여넣기**처럼 동작하므로, 같은 헤더를 여러 번 include 하면 중복 정의로 오류.
> 헤더(`클래스이름.h`) 를 아래처럼 감싸서 막는다:
> ```cpp
> #ifndef 심볼
> #define 심볼
>     // ... 헤더 내용 ...
> #endif
> ```

# 접근 지정자 · const · static

## 접근 지정자 (캡슐화)

**캡슐화 = 객체 보호·보안.** 중요한 멤버는 감추고 일부만 접근 허용.

| 지정자 | 접근 허용 범위 |
|--------|----------------|
| `private` | 디폴트. **동일 클래스 멤버 함수에서만** (가장 엄격) |
| `protected` | 자기 클래스 + **상속받은 자식 클래스** |
| `public` | 모든 클래스 (밖에서 직접 접근 가능) |

> 셋 다 **같은 클래스 멤버 함수의 접근은 허용**한다.

![[image 2.png]]

- **중복·디폴트 처리**
    - 한 클래스에서 접근 지정자를 여러 번 중복 사용 가능 (`private: int x,y; ... private: bool f();`)
    - 지정하지 않으면 자동으로 **디폴트 `private`** 로 간주
- **멤버 변수를 private 로 두는 이점**
    - 외부에서 건드리면 안 되는 변수를 보호 (const 를 쓰는 이유와 동일 — 데이터 손상 방지)
    - **생성자도 private 가능** → 한 클래스에서 객체를 하나만 생성하도록 제한

> [!note] C++ 구조체(struct)
> class 와 거의 동일하지만 **디폴트 접근 지정이 `public`** (class 는 `private`).
> C 호환성 때문에 존재할 뿐 실사용은 거의 안 함 (class 가 대체).
> 구조체 객체 생성 시 `struct` 키워드 생략 가능 : ~~struct~~ `StructName obj;`

### 접근자 함수 (getter / setter)

- 접근 권한이 `public` 인 멤버 함수로, **private 멤버 변수에 간접 접근**하도록 도움
- 보통 `get~()` (값 받기) / `set~()` (조건 지정) 이름으로 구현

```cpp
class Circle {
private:
    int radius;
public:
    Circle();
    Circle(int r);
    double getArea();
    int  getRadius();       // 접근자
    bool setRadius(int r);
};

int Circle::getRadius() { return radius; }

bool Circle::setRadius(int r) {
    if (r > 30) return false;   // 유효성 검사!
    radius = r;
    return true;
}

int main() {
    Circle waffle(5);
    waffle.radius = 5;             // 오류 — private 직접 접근 불가
    waffle.setRadius(5);           // OK
    int radius = waffle.radius;    // 오류
    radius = waffle.getRadius();   // OK
}
```

> [!tip] 접근자 함수의 장점
> 멤버를 보호하면서도 읽어올 수 있고, 접근 지정자만 쓰는 것보다 **더 세밀한 레벨의 접근 권한**을 준다.
> `setRadius` 처럼 **유효성 검사**까지 담당 가능.

## const 객체와 const 멤버 함수

- **const 객체** : 값을 변경하지 않기로 약속한 객체. 보통 함수의 **입력 인자**로 전달할 때 사용
- **const 멤버 함수** : 내부 로직에 멤버 변수 변형이 없는 함수. 이름 뒤에 `const` 를 붙임 (`void show() const;`)
    - 컴파일러는 스스로 판단 못 하므로 **반드시 명시**해야 함

```cpp
class CP {
public:
    int b;
    void a(int num);
    void show() const;   // const 멤버 함수 (명시 필수)
};

int main() {
    const CP myP;
    myP.b = 3;      // 오류 — const 객체의 일반 멤버 변수 변경
    myP.a(1);       // 오류 — const 객체의 일반 멤버 함수 호출
    myP.show();     // OK   — const 멤버 함수는 호출 가능
}
```

> [!warning] const 객체는 const 멤버 함수만 호출 가능
> - const 멤버 함수 안에서는 **멤버 변수 값 변경 불가** (정의 위배)
> - const 멤버 함수 안에서는 **일반 멤버 함수 호출 불가** (정의 위배)
> - 실수로 변형을 시도하면 컴파일 오류로 잡아줌

```cpp
// 지정 방법
class 클래스이름 {
    리턴형 멤버함수(인자) const;
};
리턴형 클래스이름::멤버함수(인자) const {
    // ...
}
```

## static 멤버

`static` = 변수·함수의 기억 부류 중 하나. **프로그램 시작 시 생성, 종료 시 소멸.**

- **static 멤버** = 프로그램 시작 시 생성, **클래스당 하나만** 생성 → 모든 인스턴스가 **공유** ("클래스 멤버")
- **non-static 멤버** = 객체 생성 시마다 각 객체 내에 생성 ("인스턴스 멤버")

```cpp
class Person {
public:
    double money;                    // 개인 소유 (인스턴스 멤버)
    void addMoney(int money) {
        this->money += money;        // this = addMoney 를 부른 객체의 주소
    }

    static int sharedMoney;          // 공금 (static 멤버 변수)
    static void addShared(int n) {   // static 멤버 함수
        sharedMoney += n;
    }
};

// 클래스 선언은 공간 할당이 아니므로, static 변수는 전역으로 따로 정의해야 함
int Person::sharedMoney = 10;        // 클래스이름::static변수 = 초기값;
```

> [!warning] static 멤버 변수는 외부(전역) 정의가 필수
> 전역 외부 정의가 없으면 **링크 단계 오류**. 이 정의가 있어야 static 변수의 공간이 실제로 할당된다.

- **static vs non-static**
    - static(클래스 멤버) = 단 하나, 모든 객체가 공유
    - non-static(인스턴스 멤버) = 객체마다 생성, 공유 안 됨
- **접근 방법 3가지**
    - `객체.static멤버`
    - `클래스명::static멤버`  ← 객체 없이도 접근
    - `객체포인터->static멤버`

```cpp
Counter::increment();          // 객체 없이 클래스명::static함수
Person lee;
lee.sharedMoney = 500;         // 객체.static멤버
Person* p = &lee;
p->addShared(200);             // 객체포인터->static멤버
```

**정적 멤버 함수**는 객체 없이 호출 가능하지만, `this` 포인터가 없다 (특정 객체 소유가 아니므로).

```cpp
#include <iostream>
using namespace std;

class Counter {
private:
    static int count;               // 정적 멤버 변수
public:
    static void increment() { count++; }
    static int  getCount()  { return count; }
};

int Counter::count = 0;             // 정적 멤버 변수 정의

int main() {
    Counter::increment();
    Counter::increment();
    Counter::increment();
    cout << "카운트 값: " << Counter::getCount() << endl;  // 3
    return 0;
}
```

> [!note] static 활용과 접근 규칙
> - 전역 변수/함수를 클래스에 **캡슐화**하는 용도 (전역 대신 static 멤버로)
> - 객체 사이 **공유 변수**를 만들 때 static 멤버 사용
> - **static 멤버 함수는 static 멤버만 접근 가능** — non-static 멤버는 접근 불가 (객체 생성 시점이 아니므로)
> - 반대로 **non-static 멤버는 static 에 접근 가능** (static 은 모든 객체 공유)
> - 주의: non-static 멤버는 클래스명으로 접근 불가
