#### 1. C++ STL 필수 재료 5개 손에 익히기

프로그래머스 환경에서는 C++ 라이브러리를 얼마나 손쉽게 꺼내 쓰느냐가 속도를 결정합니다.

- **`std::vector`:** `.push_back()`, Iterator 범위 생성자, `v.begin()`, `v.end()`
    
- **`std::unordered_map` / `unordered_set`:** 프로그래머스 '해시' 카테고리 필수 (O(1) 탐색).
    
- **`std::sort`:** Custom Comparator (람다 함수 또는 구조체 연산자 오버로딩)로 정렬 조건 자유자재로 주기.
    
- **`std::priority_queue`:** '힙(Heap)' 카테고리 필수 (기본은 최대힙, `greater<int>` 붙이면 최소힙).
    
- **`std::string` 전처리:** `substr()`, `find()`, `to_string()`, `stoi()` 등 문자열 조작.

## 🎯 코테 필수 유형 체크리스트

### 1. 기본 자료구조 & 기초 (말씀하신 항목)

- **스택 / 큐 / 덱 / 우선순위 큐 (Priority Queue)**
    
- **재귀 (Recursion)**
    
- **탐색 & 정렬 (Sorting & Search)**
    
    - _추가 권장:_ **이진 탐색 (Binary Search)** 🌟
        
        - $O(N)$으로 풀면 시간 초과 나는 문제에서 $O(\log N)$으로 줄여주는 필수 테크닉입니다. (C++에서는 `std::lower_bound`, `std::upper_bound` 활용)
            

### 2. 탐색 & 심화 탐색

- **완전탐색 (Brute Force)**
    
    - _추가 권장:_ **백트래킹 (Backtracking)** 🌟
        
        - 완전탐색을 하되, 가능성 없는 경로는 가지치기(Pruning)하는 기법입니다. (N-Queen, 수열 만들기 등)
            
- **그래프 (Graph)**
    
    - **BFS / DFS** 🌟 (그래프/격자 탐색의 알파이자 오메가입니다. 무조건 100번 이상 연습해야 함)
        
    - _추가 권장:_ **최단 경로 알고리즘**
        
        - **다익스트라 (Dijkstra):** 우선순위 큐(Heap)를 활용해 최단 거리를 구하는 문제로 자주 출제됩니다.
            
    - _추가 권장:_ **유니온 파인드 (Disjoint Set / Union-Find)**
        
        - "두 노드가 같은 집합에 속해있는가?"를 판별할 때 씁니다.
            

### 3. 문제 해결 패러다임

- **그리디 (Greedy)**
    
    - "현재 상황에서 가장 좋은 것만 선택"하는 테크닉입니다. 보통 정렬(`sort`)이나 우선순위 큐와 짝꿍으로 많이 나옵니다.
        
- **동적 계획법 (DP - Dynamic Programming)**
    
    - 점화식 세우기 + 메모이제이션(Memoization). 난이도가 있는 편이라 기초 DP(1차원/2차원 배열) 위주로 단단하게 잡는 것을 추천합니다.
        
- _추가 권장:_ **투 포인터 (Two Pointers) / 슬라이딩 윈도우** 🌟
    
    - 1차원 배열에서 두 개의 인덱스(포인터)를 움직이며 $O(N)$으로 답을 찾는 기법으로, 구현도 쉬운데 출제 빈도가 매우 높습니다.
