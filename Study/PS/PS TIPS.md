### 📏 PS 자료형 선택 가이드 (범위별 팁)

- **$10^9$ (10억) 근처 또는 그 이상의 값이 예상될 때**
    
    - **무조건 `long long` 사용:** `int`의 최대 표현 범위는 약 $2 \times 10^9$ 이기 때문에, 연산 과정에서 값이 조금만 더 커지거나 곱해지면 오버플로우(Overflow)가 발생하여 쓰레기 값이 들어가게 됨.
        
- **자료형 혼용 주의**
    
    - `int`와 `long long`을 섞어서 쓰면 은근히 잡기 힘든 타입 캐스팅 에러나 오버플로우가 발생하기 쉬우므로, 값이 커질 여지가 있는 로직에서는 누적합, 계산 결과, 범위 변수 모두 `long long`으로 선언하는 것 추천



### 🚀 PS 고수들의 실전 디버깅 꿀팁

그래도 막상 꼬였을 때 `cout`을 쓰고 지우는 게 귀찮잖아요? 그럴 땐 고수들이 쓰는 **'조건부 디버깅(매크로)'** 방식을 추천해요.

코드 맨 위에 아래처럼 매크로를 하나 만들어두는 거예요.

C++

```
#include <iostream>
using namespace std;

// 제출할 때는 이 줄을 주석 처리(//) 하거나 지우면 됨!
#define DEBUG 

#ifdef DEBUG
#define D(x) cout << "[DEBUG] " << #x << " = " << x << '\n'
#else
#define D(x)
#endif
```

- **사용법:** 코드를 짜다가 변수 값이 궁금하면 `D(temp);` 라고만 적어두면 돼요.
    
- **장점:** 나중에 제출할 때 일일이 `cout`을 찾아서 지울 필요 없이, 맨 위의 `#define DEBUG` 한 줄만 지우면 모든 디버깅 출력이 마법처럼 사라져서 엄청 안전하고 편해요!
