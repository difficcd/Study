### 파인튜닝 참고사항

**약한 버전** — "LoRA 튜토리얼 따라해서 GPT를 어떤 도메인의 QA봇으로 만들었다" 정도면, 사실 이건 요즘 흔해. 파인튜닝 튜토리얼은 널려 있어서, 결과물만 있으면 "따라했구나" 이상의 인상을 주기 어려워.

 **(1) 데이터를 직접 설계·검증했다** (네가 Fable/GPT로 생성 후 직접 품질 검증한 파이프라인이 있다는 것 자체가 "데이터 큐레이션 역량"을 보여줌), **(2) 학습 전/후를 정량적으로 비교했다** (정성적 "됐다" 말고 벤치마크 수치), **(3) 왜 이 방법(LoRA vs full fine-tune, 데이터 크기별 성능 변화 등)을 선택했는지 설명 가능하다.** 이 세 개가 있으면, "파인튜닝 따라해봄"이 아니라 **"데이터 파이프라인부터 평가까지 전체 사이클을 이해하고 실행한 사람"** 으로 읽혀. 

즉 결론은 — **모델을 튜닝했다는 사실 자체보다, 그 과정에서 네가 뭘 판단하고 측정했는지가 가치를 만들어.** 재미로 시작해도 되는데, 하다가 "그냥 됐다" 수준에서 멈추지 말고 벤치마크 비교까지 가면 진짜 포트폴리오가 돼.
