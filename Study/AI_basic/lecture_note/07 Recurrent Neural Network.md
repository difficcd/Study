# 07-01 순환 신경망 (Recurrent Neural Network, RNN)

RNN(Recurrent Neural Network)은 시퀀스(Sequence) 모델입니다. 

입력과 출력을 시퀀스 단위로 처리하는 모델입니다. 
번역기를 생각해보면 입력은 번역하고자 하는 문장. 즉, 단어 시퀀스입니다. 
출력에 해당되는 번역된 문장 또한 단어 시퀀스입니다. 

이러한 시퀀스들을 처리하기 위해 고안된 모델들을 시퀀스 모델이라고 합니다. 
그 중에서도 RNN은 딥 러닝에 있어 가장 기본적인 시퀀스 모델입니다.

```
용어는 비슷하지만 순환 신경망과 재귀 신경망(RvNN = Recursive Neural Network)은  전혀 다른 개념입니다.  
```

## 1. 순환 신경망(Recurrent Neural Network, RNN)

앞서 배운 신경망들은 전부 은닉층에서 활성화 함수를 지난 값은 
<< 오직 출력층 방향으로만 >> 향했습니다. 

이와 같은 신경망들을 피드 포워드 신경망(Feed Forward Neural Network)이라고 합니다. 그런데 그렇지 않은 신경망들이 있습니다. RNN(Recurrent Neural Network) 또한 그 중 하나입니다. RNN은 은닉층의 노드에서 활성화 함수를 통해 나온 결과값을 << 출력층 방향으로도 보내면서, 다시 은닉층 노드의 << 다음 계산의 입력으로 >> 보내는 특징을 갖고있습니다. >>
(아래 그림을 보면 재귀 같지만, RNN에서의 Recurrent 가 순환인 만큼 : 시간축=타임스탬프에 따라 loop를 도는 구조이기 때문에, 시간을 펼쳐=unfolding보면 재귀가 아니라 옆으로 긴 신경망으로 보이게 됨.)

![](https://static.wikidocs.net/images/page/22886/rnn_image1_ver2.PNG)

이를 그림으로 표현하면 위와 같습니다. $x$는 입력층의 입력 벡터, $y$는 출력층의 출력 벡터입니다. 실제로는 편향 $b$도 입력으로 존재할 수 있지만 앞으로의 그림에서는 생략합니다.

RNN에서 은닉층에서 <<활성화 함수를 통해 결과를 내보내는 역할>> 을 하는 노드를 << 셀(cell) >> 이라고 합니다. 이 셀은 이전의 값을 기억하려고 하는 일종의 메모리 역할을 수행하므로 이를 **메모리 셀** 또는 **RNN 셀**이라고 표현합니다.
(셀 = 순환이 이루어지는 은닉층의 한 노드 = 기억 장치를 가져 스스로 상태 유지하며 순환 연산 하는 노드=>셀! )

은닉층의 메모리 셀은 각각의 "시점"(time step)에서 바로 이전 시점에서의 은닉층의 메모리 셀에서 나온 값을 자신의 입력으로 사용하는 << 재귀적 활동을 하고 있습니다. >>

앞으로는 현재 시점을 변수 t로 표현하겠습니다. 
이는 현재 시점 t에서의 메모리 셀이 갖고있는 값은 << 과거의 메모리 셀들의 값에 영향을 받은 것>>임을 의미합니다. 그렇다면 메모리 셀이 갖고 있는 이 값은 뭐라고 부를까요?

메모리 셀이 출력층 방향으로 또는 다음 시점 t+1의 자신에게 보내는 값을 **은닉 상태(hidden state)** 라고 합니다. 다시 말해 t 시점의 메모리 셀은 t-1 시점의 메모리 셀이 보낸 은닉 상태값을 t 시점의 은닉 상태 계산을 위한 입력값으로 사용합니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image2_ver3.PNG)

RNN을 표현할 때는 일반적으로 위의 그림에서 좌측과 같이 화살표로 사이클을 그려서 재귀 형태로 표현하기도 하지만, 우측과 같이 사이클을 그리는 화살표 대신 여러 시점으로 펼쳐서 표현하기도 합니다. 두 그림은 동일한 그림으로 단지 사이클을 그리는 << 화살표를 사용하여 표현하였느냐, 시점의 흐름에 따라서 표현하였느냐의 차이 >> 일 뿐 둘 다 동일한 RNN을 표현하고 있습니다.

피드 포워드 신경망에서는 뉴런이라는 단위를 사용했지만, RNN에서는 뉴런이라는 단위보다는 << 입력층과 출력층에서는 각각 입력 벡터와 출력 벡터, 은닉층에서는 은닉 상태라는 표현을 주로 사용 >> 합니다. 

그래서 사실 위의 그림에서 회색과 초록색으로 표현한 각 네모들은 기본적으로 <<벡터 단위>> 를 가정하고 있습니다. 

피드 포워드 신경망과의 차이를 비교하기 위해서 
RNN을 뉴런 단위로 시각화해보겠습니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image2.5.PNG)

위의 그림은 입력 벡터의 차원이 4, 은닉 상태의 크기가 2(타임스탬프랑 상관 없음. 사실상 셀의 개수랑 동일한 것임. hidden state 전달개수=hiddenstate개수(일대일)이니까) ,
출력층의 출력 벡터의 차원이 2인 RNN이 시점이 2일 때의 모습을 보여줍니다. 다시 말해 뉴런 단위로 해석하면 입력층의 뉴런 수는 4, 은닉층의 뉴런 수는 2, 출력층의 뉴런 수는 2입니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image3_ver2.PNG)

RNN은 입력과 출력의 길이를 다르게 설계 할 수 있으므로 다양한 용도로 사용할 수 있습니다. 위 그림은 입력과 출력의 길이에 따라서 달라지는 RNN의 다양한 형태를 보여줍니다. 위 구조가 자연어 처리에서 어떻게 사용될 수 있는지 예를 들어봅시다. RNN 셀의 각 시점 별 입, 출력의 단위는 사용자가 정의하기 나름이지만 가장 보편적인 단위는 '단어 벡터'입니다. 

 일대다 = 입력하나 출력여럿 : 사진 한장 주고 설명하게 하기 등
 다대일 = 여러 타임스탬프의 연속데이터 다 읽고 난 뒤 정답은 한개만 출력
	     (감정 분석 후 긍정 부정 출력, 지난 30일간의 주가 흐름 (시퀀스 입력) 
	     $\rightarrow$ **"내일 주가"** (출력 1개)  등..)
 다대다 = 설명을 줘서 설명을 출력하게 함  

예를 들어 하나의 입력에 대해서 여러개의 출력(one-to-many)의 모델은 
하나의 이미지 입력에 대해서 사진의 제목을 출력하는 이미지 캡셔닝(Image Captioning) 작업에 사용할 수 있습니다. 사진의 제목은 단어들의 나열이므로 시퀀스 출력입니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image3.5.PNG)

또한 단어 시퀀스에 대해서 하나의 출력(many-to-one)을 하는 모델은 입력 문서가 긍정적인지 부정적인지를 판별하는 감성 분류(sentiment classification), 또는 메일이 정상 메일인지 스팸 메일인지 판별하는 스팸 메일 분류(spam detection)에 사용할 수 있습니다. 위 그림은 RNN으로 스팸 메일을 분류할 때의 아키텍처를 보여줍니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image3.7.PNG)

다 대 다(many-to-many)의 모델의 경우에는 입력 문장으로 부터 대답 문장을 출력하는 챗봇과 입력 문장으로부터 번역된 문장을 출력하는 번역기, 개체명 인식이나 품사 태깅과 같은 작업이 속합니다. 위 그림은 개체명 인식을 수행할 때의 RNN 아키텍처를 보여줍니다.

이제 RNN에 대한 수식을 정의해보겠습니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image4_ver2.PNG)

현재 시점 t에서의 은닉 상태값을 $h_{t}$라고 정의하겠습니다. 
은닉층의 메모리 셀은 $h_{t}$를 계산하기 위해서 총 두 개의 가중치를 갖게 됩니다. 
하나는 입력층에서 입력값을 위한 가중치 $W_{x}$이고, 
하나는 이전 시점 t-1의 은닉 상태값인 $h_{t-1}$을 위한 가중치 $W_{h}$입니다.
=> RNN에서는 은닉상태값자체를변형/조절하기위한 별도의 가중치가 존재함. (W_h가 그것. 이게 없으면 과거 기억과 현재 기억 입력 비중을 조절 불가한 것.
W_h = 기억용 가중치. 기억을 얼마나 중요하게 반영할지를 판가름,
W_x = 입력용 가중치 : 지금 들어온 새 정보를 얼마나 반영할지를 판단. )

이를 식으로 표현하면 다음과 같습니다.

- 은닉층  
    $h_{t} = tanh(W_{x} x_{t} + W_{h}h_{t−1} + b)$
    
- 출력층  
    $y_{t} = f(W_{y}h_{t} + b)$  
    단, $f$는 비선형 활성화 함수 중 하나.
    

RNN의 은닉층 연산을 벡터와 행렬 연산으로 이해할 수 있습니다. 
자연어 처리에서 RNN의 입력 $x_{t}$는 < 대부분의 경우에서 단어 벡터로 간주할 수 있는데, 단어 벡터의 차원을 $d$라고 하고, 은닉 상태의 크기를 $D_{h}$라고 하였을 때 각 벡터와 행렬의 크기는 다음과 같습니다. >
(은닉상태크기=차원=은닉층노드수)

$x_{t}$ : $(d × 1)$  
$W_{x}$ : $(D_{h} × d)$  
$W_{h}$ : $(D_{h} × D_{h})$  
$h_{t-1}$ : $(D_{h} × 1)$  
$b$ : $(D_{h} × 1)$

배치 크기가 1이고, $d$와 $D_{h}$ 두 값 모두를 4로 가정하였을 때, RNN의 은닉층 연산을 그림으로 표현하면 아래와 같습니다.

![](https://static.wikidocs.net/images/page/22886/rnn_images4-5.PNG)

이때 $h_{t}$를 계산하기 위한 활성화 함수로는 주로 하이퍼볼릭탄젠트 함수(tanh)가 사용되지만, ReLU로 바꿔 사용하는 시도도 있습니다.
(tanh : 원래 ReLU가 딥러닝 표준인데, RNN은 왜 tanh일까?
=> RNN특유의 순환구조=반복연산때문에 값의 폭발 막고 음수/양수 정보 둘 다 유지해야 하기 떄문이라고 함. ReLU를 쓰면 : 값 범위가 x>0 에서 ~무한대까지 늘어날 수 있어 폭발/발산하기쉽지만 tanh 범위는 -1~1범위로 잘 커버해주고, 원점 대칭이기 때문에 방향적 의미를 잘 조절할 수 있음. : 정보를 강화하거나 억제해야하는 상황이 많아서!)
(ReLU : IRNN 등에서 쓰려는 시도는 있지만.. 가중치초기화 세팅을 정밀하게 안 하면 RNN 특성상 쓰기가 매우 까다로움 : 기울기 발산 아니면 소실로 극단적인 불안정성을 보이기 떄문에 보통 전통적 RNN에서는 tanh가 표준처럼 채택되어왔다고 함.)

위의 식에서 각각의 가중치 $W_{x}$, $W_{h}$, $W_{y}$의 값은 << 모든 시점에서 값을 동일하게 공유합니다.(타임스탬프, 시점 상관없이 공유한다는 것.) 
만약, 은닉층이 2개 이상일 경우에는 은닉층 2개의 가중치는 서로 다릅니다. >>

출력층은 결과값인 $y_{t}$를 계산하기 위한 활성화 함수로는 << 상황에 따라 다를텐데, 예를 들어서 이진 분류를 해야하는 경우라면 시그모이드 함수를 사용할 수 있고 다양한 카테고리 중에서 선택해야하는 문제(다부류 활성화함수)라면 소프트맥스 함수를 사용하게 될 것입니다. >>

## 2. 파이썬으로 RNN 구현하기

직접 Numpy로 RNN 층을 구현해보겠습니다. 
앞서 메모리 셀에서 은닉 상태를 계산하는 식을 다음과 같이 정의하였습니다.

$h_{t} = tanh(W_{x}X_{t} + W_{h}h_{t−1} + b)$

실제 구현에 앞서 간단히 의사 코드(pseudocode)를 작성해보겠습니다.

```python
# 아래의 코드는 의사 코드(pseudocode)로 실제 동작하는 코드가 아님. 

hidden_state_t = 0 # 초기 은닉 상태를 0(벡터)로 초기화
for input_t in input_length: # 각 시점마다 입력을 받는다.
    output_t = tanh(input_t, hidden_state_t) 
          # 각 시점에 대해서 입력과 은닉 상태를 가지고 연산
    hidden_state_t = output_t 
          # 계산 결과는 현재 시점의 은닉 상태가 된다.
```

우선 t 시점의 은닉 상태를 hidden_state_t라는 변수로 선언하였고, 
입력 데이터의 길이를 input_length로 선언하였습니다. 
이 경우, 입력 데이터의 길이는 곧 총 시점의 수(timesteps)가 됩니다. 
( 예시 : i love you 문장의 경우, 입력데이터길이 3이고, RNN은 단어를 순서대로 처리해야 하니 총 3번의 루프를 돌아야 문장을 다 읽을 수 있음을 보면 이해가 쉬움! 참고로 알고는 있겠지만, 위의 의사 코드는 가중치가 생략된 코드임.)

그리고 t 시점의 입력값을 input_t로 선언하였습니다. 각 메모리 셀은 각 시점마다 input_t와 hidden_sate_t(이전 상태의 은닉 상태)를 입력으로 활성화 함수인 하이퍼볼릭탄젠트 함수를 통해 현 시점의 hidden_state_t를 계산합니다.

의사 코드를 통해 간단히 개념 정립을 해보았습니다. 
이제 RNN 층을 실제 동작되는 코드로 구현해보겠습니다. 

아래의 코드는 이해를 돕기 위해 (timesteps, input_size) 크기의 2D 텐서를 입력으로 받았다고 가정하였으나, 실제로 파이토치에서는 << (batch_size, timesteps, input_size)의 크기의 3D 텐서를 입력으로 받는 것을 기억 >> 합시다.

복습 : 

- **`2D 텐서 (timesteps, input_size)`:**
    
    - **책 1권**을 읽는 방식입니다.
    - $10$줄짜리 책($\text{timesteps}=10$)의 각 줄당 $100$자($\text{input\_size}=100$)가 들어있는 형태입니다.
    - 사람(CPU/GPU)이 한 번에 책 1권만 읽는 구조입니다.
        
- **`3D 텐서 (batch_size, timesteps, input_size)`:**
    
    - 똑같은 $10$줄짜리 책 **64권($\text{batch\_size}=64$)을 한꺼번에 펼쳐놓고** 100명이 동시에 읽는 방식입니다.
    - GPU는 이 64권의 첫 번째 줄들을 **단 한 번의 행렬 곱셈 연산으로 동시에 처리**할 수 있습니다.

timesteps = 단어 개수 (시점 개수, 순환 횟수)

```python
import numpy as np

timesteps = 10 # 시점의 수. NLP에서는 보통 문장의 길이가 된다.
input_size = 4 # 입력의 차원. NLP에서는 보통 단어 벡터의 차원이 된다.
hidden_size = 8 # 은닉 상태의 크기. 메모리 셀의 용량이다.

inputs = np.random.random((timesteps, input_size)) 
         # 입력에 해당되는 2D 텐서 (실제로는 3d 텐서 받음)

hidden_state_t = np.zeros((hidden_size,)) # 초기 은닉 상태는 0(벡터)로 초기화
# 은닉 상태의 크기 hidden_size로 은닉 상태를 만듬.
```

우선 시점, 입력의 차원, 은닉 상태의 크기, 그리고 초기 은닉 상태를 정의하였습니다. 현재 초기 은닉 상태는 0의 값을 가지는 벡터로 초기화가 된 상태입니다. 초기 은닉 상태를 출력해보겠습니다.

```python
print(hidden_state_t) # 8의 크기를 가지는 은닉 상태. 현재는 초기 은닉 상태로 모든 차원이 0의 값을 가짐.
```

```python

```

은닉 상태의 크기를 8로 정의하였으므로 8의 차원을 가지는 0의 값으로 구성된 벡터가 출력됩니다. 이제 가중치와 편향을 정의합니다.

```python
Wx = np.random.random((hidden_size, input_size))  # (8, 4)크기의 2D 텐서 생성. 입력에 대한 가중치.
Wh = np.random.random((hidden_size, hidden_size)) # (8, 8)크기의 2D 텐서 생성. 은닉 상태에 대한 가중치.
b = np.random.random((hidden_size,)) # (8,)크기의 1D 텐서 생성. 이 값은 편향(bias).
```

가중치와 편향을 각 크기에 맞게 정의하였습니다. 가중치와 편향의 크기를 출력해보겠습니다.

```python
print(np.shape(Wx))
print(np.shape(Wh))
print(np.shape(b))
```

```python

(8, 8)
(8,)
```

각 가중치와 편향의 크기는 다음과 같습니다. 
Wx는 (은닉 상태의 크기 × 입력의 차원), 
Wh는 (은닉 상태의 크기 × 은닉 상태의 크기), 
b는 (은닉 상태의 크기)의 크기를 가집니다. 

이제 모든 시점의 은닉 상태를 출력한다고 가정하고, RNN 층을 동작시켜봅시다.

```python
total_hidden_states = []

# 메모리 셀 동작
for input_t in inputs: # 각 시점에 따라서 입력값이 입력됨.
  output_t = np.tanh(np.dot(Wx,input_t) + np.dot(Wh,hidden_state_t) + b) # Wx * Xt + Wh * Ht-1 + b(bias)
  total_hidden_states.append(list(output_t)) # 각 시점의 은닉 상태의 값을 계속해서 축적
  print(np.shape(total_hidden_states)) # 각 시점 t별 메모리 셀의 출력의 크기는 (timestep, output_dim)
  hidden_state_t = output_t

total_hidden_states = np.stack(total_hidden_states, axis = 0) 
# 출력 시 값을 깔끔하게 해준다.

print(total_hidden_states) # (timesteps, output_dim)의 크기. 이 경우 (10, 8)의 크기를 가지는 메모리 셀의 2D 텐서를 출력.
```

## 5. 양방향 순환 신경망 (Bidirectional Recurrent Neural Network)

양방향 순환 신경망은 시점 t에서의 출력값을 예측할 때 << 이전 시점의 데이터뿐만 아니라, 이후 데이터로도 예측할 수 있다는 아이디어에 기반 >> 합니다.

영어 빈칸 채우기 문제에 비유하여 보겠습니다.

```python
Exercise is very effective at [          ] belly fat.

1) reducing
2) increasing
3) multiplying
```

'운동은 복부 지방을 [ ] 효과적이다'라는 영어 문장이고, 정답은 reducing(줄이는 것)입니다. 그런데 위의 영어 빈 칸 채우기 문제를 잘 생각해보면 정답을 찾기 위해서는 이전에 나온 단어들만으로는 부족합니다. <<< 목적어인 belly fat(복부 지방)를 모르는 상태라면 정답을 결정하기가 어렵습니다. >>> 

즉, RNN이 과거 시점(time step)의 데이터들을 참고해서, 찾고자하는 정답을 예측하지만 실제 문제에서는 과거 시점의 데이터만 고려하는 것이 아니라 << 향후 시점의 데이터에 힌트가 있는 경우도 많습니다. 그래서 이전 시점의 데이터뿐만 아니라, 이후 시점의 데이터도 힌트로 활용하기 위해서 고안된 것이 양방향 RNN입니다. >>

![](https://static.wikidocs.net/images/page/22886/rnn_image5_ver2.PNG)

양방향 RNN은 하나의 출력값을 예측하기 위해 
<< 기본적으로 두 개의 메모리 셀을 사용 >> 합니다. 

첫번째 메모리 셀은 앞에서 배운 것처럼 **앞 시점의 은닉 상태(Forward States)** 를 전달받아 현재의 은닉 상태를 계산합니다. 위의 그림에서는 주황색 메모리 셀에 해당됩니다. << 두번째 메모리 셀은 앞에서 배운 것과는 다릅니다. 앞 시점의 은닉 상태가 아니라 **뒤 시점의 은닉 상태(Backward States)** 를 전달 받아 현재의 은닉 상태를 계산 >> 합니다. 위의 그림에서는 초록색 메모리 셀에 해당됩니다. 그리고 이 두 개의 값 모두가 << 출력층에서 출력값을 예측하기 위해 사용됩니다. >> 

물론, 양방향 RNN도 << 다수의 은닉층 >> 을 가질 수 있습니다. 
아래의 그림은 양방향 순환 신경망에서 은닉층이 1개 더 추가되어 
은닉층이 2개인 깊은(deep) 양방향 순환 신경망의 모습을 보여줍니다.

![](https://static.wikidocs.net/images/page/22886/rnn_image6_ver3.PNG)

다른 인공 신경망 모델들도 마찬가지이지만, 은닉층을 무조건 추가한다고 해서 모델의 성능이 좋아지는 것은 아닙니다. 

은닉층을 추가하면, 학습할 수 있는 양이 많아지지만

2배가 된다 => 연결이란 무엇인가?

숫자로 된 벡터 두 개가 있다고 해볼게요.

- **정방향 RNN이 만든 기억 ($h_{forward}$):** `[1, 2, 3]` (길이 = 3)
- **역방향 RNN이 만든 기억 ($h_{backward}$):** `[4, 5, 6]` (길이 = 3)


이 두 개를 연결(Concatenate)하면 나란히 옆으로 붙어서 다음과 같아집니다.

- **양방향 합성 기억 ($h_{final}$):** `[1, 2, 3, 4, 5, 6]` (길이 = 6, 즉 **$3 \times 2$**)


더하거나 곱해서 값을 뭉개는 것이 아니라, 
**두 기억을 손실 없이 옆으로 길게 이어 붙이는 것**입니다.

#### 양방향 RNN(Bi-RNN)에서 일어나는 일

양방향 RNN은 문장을 두 번 읽습니다.

1. **정방향 셀(Forward Cell):** 문장을 왼쪽에서 오른쪽으로 읽으며 과거의 문맥을 기억함 $\rightarrow$ 은닉 크기 $H$
    
2. **역방향 셀(Backward Cell):** 문장을 오른쪽에서 왼쪽으로 읽으며 미래의 문맥을 기억함 $\rightarrow$ 은닉 크기 $H$


각 시점($t$)마다 정방향 기억($H$)과 역방향 기억($H$)이 각각 1개씩 튀어나옵니다.

나는 여기서나온 아웃풋이랑 스테이터스로다가 에포크돌려서 학습시켜서 출력시키면 단어에대한추론도 가능해지는거야 어느정도는?


#### 1. "가공은 이후 층에서 받아서 하는 거야?" $\rightarrow$ **YES!**

맞습니다. `Bi_RNN` 모듈이 해주는 역할은 << "문장을 양방향으로 훑어서 특징(맥락)을 풍부하게 뽑아낸 텐서를 만들어주는 것"까지 >> 입니다.

이렇게 뽑혀 나온 16차원짜리 벡터(`outputs` 또는 `_status`)를 이후 출력층(`nn.Linear`)으로 전달해서 최종 가공(예측)을 하게 됩니다.

- **감성 분석(긍정/부정 2개 분류) 예시:**
 
```Python
    # Bi-RNN에서 나온 outputs: (1, 10, 16)
    # 마지막 시점 t=10의 은닉 상태(16차원)만 뽑아냄
    last_hidden = outputs[:, -1, :]  # Shape: (1, 16)
    
    # 선형 레이어(Linear)에 넣어서 2개의 클래스 점수로 가공!
    fc = nn.Linear(16, 2)
    prediction = fc(last_hidden)     # Shape: (1, 2)
```


#### 2. "이렇게 구성해 준 다음 데이터만 넣고... 학습시키면 추론 가능해?" $\rightarrow$ **YES!**

네! 내부의 양방향 연결(Concat), 순방향/역방향 가중치 행렬 계산 등 복잡한 수학 연산은 **PyTorch가 `bidirectional=True` 옵션 하나로 알아서 내부에서 구성**해 줍니다.

개발자가 할 일은 아주 단순합니다.

1. **모델 정의:** `bidirectional=True` 옵션으로 Bi-RNN 선언
2. **데이터 전달:** `outputs, _status = cell(inputs)` 형태로 데이터 통과
3. **Loss & Optimizer 연결:** 출력값과 정답 라벨의 오차(Loss)를 구하고 `loss.backward()`로 **에포크(Epoch)를 돌려 가중치를 학습**

이렇게 학습을 몇 에포크 돌리고 나면, 모델은 단어 간의 앞뒤 문맥 패턴을 익히게 되어 **문장 분류, 품사 태깅, 단어 추론 같은 NLP 작업을 훌륭하게 수행**하게 됩니다.

#### 🛠️ 실무에서 쓰는 진짜 모델 클래스 예시

지금 이해하신 흐름이 코드상에서 `nn.Module` 클래스로 묶이면 아래와 같은 모습이 됩니다.

```Python
import torch
import torch.nn as nn

class MyTextClassifier(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        # 1. 양방향 RNN 레이어
        self.rnn = nn.RNN(input_size=input_size, 
                          hidden_size=hidden_size, 
                          num_layers=2, 
                          batch_first=True, 
                          bidirectional=True) # 알아서 가중치 2배 구성!
        
        # 2. 가공을 위한 최종 출력층 (hidden_size * 2 -> 원하는 클래스 수)
        self.fc = nn.Linear(hidden_size * 2, num_classes)

    def forward(self, x):
        # outputs shape: (batch, time, hidden_size * 2)
        outputs, _status = self.rnn(x)
        
        # 문장의 마지막 타임스텝의 기억(16차원)을 가져옴
        last_hidden = outputs[:, -1, :] 
        
        # 출력층에서 2차원으로 가공하여 반환
        logits = self.fc(last_hidden)
        return logits

# --- 사용 예시 ---
model = MyTextClassifier(input_size=5, hidden_size=8, num_classes=2)
inputs = torch.Tensor(1, 10, 5) # (배치 1, 길이 10, 차원 5)

# 예측 수행 (에포크 돌리면서 이 prediction으로 loss 계산!)
prediction = model(inputs) 
print(prediction.shape) # torch.Size([1, 2])
```

#### 💡 요약

- **파이토치 Bi-RNN:** complex한 양방향 구조와 차원 연산을 알아서 다 해준다.
    
- **사용자(개발자):** 거기서 나온 `outputs` (또는 `_status`)를 받아서 `nn.Linear`에 넣어 **원하는 형태(분류 개수 등)로 가공**한 뒤, 에포크를 돌려 학습시키면 끝!

차근차근 짚어드리면서 정확한 흐름으로 바로잡아 드릴게요.

### 1. 첫 번째 파트: 감정분석 예시 검증 & 수정

#### ① 단어 개수 10개, 문장 개수 4개?

- **단어 개수 10개 (`timesteps = 10`):** **맞습니다!** 한 문장을 이루는 단어(시퀀스 길이)가 10개라는 뜻입니다.
    
- **문장 개수 4개 (`input_size = 4`???):** **아닙니다! 💡**
    
    - `input_size = 4`는 문장의 개수가 아니라 '단어 1개를 표현하는 벡터의 차원 수(특징 수)'입니다. (예: 단어를 4차원 숫자로 표현함)
        
    - 문장의 개수는 `batch_size`로 설정해야 합니다. (예: `batch_size = 4`면 문장 4개를 한 번에 처리) => 문장자체가 바로 들어갈수있는게아니라 임베딩이되어야들어가니까... 당연한건데 제대로 생각을 못한듯.
        
### ② 8층의 은닉층?

- **아닙니다! 💡**
    
    - `hidden_size = 8`은 은닉층을 8층 쌓았다는 뜻이 아니라, **은닉층 내부의 노드(기억 메모리) 개수가 8개**라는 뜻입니다.
        
    - 은닉층을 8개 쌓으려면 `num_layers = 8`로 설정해야 합니다. (아까 코드에서는 1층 또는 2층이었습니다.) => 이것도 hidden_size = hidden_state_size 임.
        

## 2. 두 번째 파트: MLP vs DRNN vs RNN 개념 정리

> **"MLP(DRNN기준) 에다가 타임스탬프 : 입력 단위(단어)사이 관계 반영하는게 RNN인것이 맞나"**

**네, 핵심을 완벽하게 파악하셨습니다!**

조금 더 직관적으로 비교해 드리자면:

- **MLP (다층 퍼셉트론):**
    
    - 입력 데이터 간의 **'순서(시간)' 개념이 없습니다.** 단어 A, B, C를 넣으면 그냥 한 번에 섞어서 처리합니다.
    
- **DRNN (Deep RNN):**
    
    - MLP처럼 은닉층을 위로 여러 층(Deep) 쌓아 올렸지만, 거기에 **'타임스탬프(시간의 흐름)' 개념과 '자기 자신으로 돌아오는 순환 구조'를 추가**한 것입니다.
        
    - 덕분에 *"이전 단어가 다음 단어에 미치는 영향(문맥)"*을 기억하고 반영할 수 있게 됩니다.
        

## 🛠️ 올바른 감정분석(3가지 감정 분류) 전체 흐름 요약

만약 **"문장 4개(Batch=4), 문장당 단어 10개(Time=10), 단어 차원 5차원(Input=5)"** 데이터를 3가지 감정(긍정/중립/부정)으로 분류한다면 최종 구조는 다음과 같습니다.

```
1. [입력 데이터]  Shape: (batch=4, timesteps=10, input_size=5)
       │
       ▼
2. [RNN 은닉층]   10번의 타임스텝 동안 순환 연산 수행 (hidden_size=8)
       │
       ▼
3. [마지막 기억]  t=10 시점의 은닉 상태값만 추출 -> Shape: (4, 8)
       │
       ▼
4. [출력 linear]  nn.Linear(8, 3) 통과 -> 3개 클래스 점수 출력 -> Shape: (4, 3)
       │
       ▼
5. [활성화함수]  Softmax 통과 (다부류 분류이므로!) -> 최종 확률 산출
       │
       ▼
6. [에포크 학습]  정답과 비교하여 Loss 계산 -> BPTT로 가중치(Wx, Wh, b) 갱신!
```

개념의 큰 틀은 아주 잘 잡고 계십니다! 파라미터의 이름이 가진 의미(`input_size` = 단어 차원, `batch_size` = 문장 개수, `hidden_size` = 은닉 노드 수)만 명확히 구분하시면 완벽합니다.






# 07-02 LSTM과 GRU

바닐라 아이스크림이 가장 기본적인 맛을 가진 아이스크림인 것처럼, 
앞서 배운 RNN을 가장 단순한 형태의 RNN이라고 하여 바닐라 RNN(Vanilla RNN)이라고 합니다. (케라스에서는 SimpleRNN) 

바닐라 RNN 이후 바닐라 RNN의 한계를 극복하기 위한 다양한 RNN의 변형이 나왔습니다. 이번 챕터에서 배우게 될 LSTM도 그 중 하나입니다. 

앞으로의 설명에서 LSTM과 비교하여 RNN을 언급하는 것은 전부 바닐라 RNN을 말합니다.

## 1. 바닐라 RNN의 한계

![](https://static.wikidocs.net/images/page/22888/lstm_image1_ver2.PNG)

앞 챕터에서 바닐라 RNN은 출력 결과가 이전의 계산 결과에 의존한다는 것을 언급한 바 있습니다. 하지만 바닐라 RNN은 비교적 짧은 시퀀스(sequence)에 대해서만 효과를 보이는 단점이 있습니다. 

바닐라 RNN의 시점(time step)이 길어질 수록 앞의 정보가 뒤로 충분히 전달되지 못하는 현상이 발생합니다. 
위의 그림은 첫번째 입력값인 $x_{1}$의 정보량을 짙은 남색으로 표현했을 때, 색이 점차 얕아지는 것으로 시점이 지날수록 $x_{1}$의 정보량이 손실되어가는 과정을 표현하였습니다. 

뒤로 갈수록 $x_{1}$의 정보량은 손실되고, 시점이 충분히 긴 상황에서는 $x_{1}$의 전체 정보에 대한 영향력은 << 거의 의미가 없을 수도 있습니다. >> 

어쩌면 가장 중요한 정보가 시점의 앞 쪽에 위치할 수도 있습니다. RNN으로 만든 언어 모델이 다음 단어를 예측하는 과정을 생각해봅시다. 예를 들어 ''모스크바에 여행을 왔는데 건물도 예쁘고 먹을 것도 맛있었어. 그런데 글쎄 직장 상사한테 전화가 왔어. 어디냐고 묻더라구 그래서 나는 말했지. 저 여행왔는데요. 여기 \_\_\_'' 다음 단어를 예측하기 위해서는 장소 정보가 필요합니다. 

그런데 장소 정보에 해당되는 단어인 '모스크바'는 앞에 위치하고 있고, RNN이 충분한 기억력을 가지고 있지 못한다면 다음 단어를 엉뚱하게 예측합니다.

이를 **장기 의존성 문제(the problem of Long-Term Dependencies)** 라고 합니다.

## 2. 바닐라 RNN 내부 열어보기

![](https://static.wikidocs.net/images/page/22888/vanilla_rnn_ver2.PNG)

LSTM에 대해서 이해해보기 전에 바닐라 RNN의 뚜껑을 열어보겠습니다. 
위의 그림은 바닐라 RNN의 내부 구조를 보여줍니다. 
이 책에서는 RNN 계열의 인공 신경망의 그림에서는 편향 $b$를 생략합니다. 위의 그림에 편향 $b$를 그린다면 $x_{t}$ 옆에 tanh로 향하는 또 하나의 입력선을 그리면 됩니다. 

$h_{t} = tanh(W_{x}x_{t} + W_{h}h_{t−1} + b)$

바닐라 RNN은 $x_{t}$와 $h_{t-1}$이라는 두 개의 입력이 각각의 가중치와 곱해져서 메모리 셀의 입력이 됩니다. 그리고 이를 하이퍼볼릭탄젠트 함수의 입력으로 사용하고 이 값은 은닉층의 출력인 은닉 상태 (hidden state) 가 됩니다.

## 3. LSTM(Long Short-Term Memory)

![](https://static.wikidocs.net/images/page/22888/vaniila_rnn_and_different_lstm_ver2.PNG)

위의 그림은 LSTM의 전체적인 내부의 모습을 보여줍니다. 
전통적인 RNN의 이러한 단점을 보완한 RNN의 일종을 장단기 메모리(Long Short-Term Memory)라고 하며, 줄여서 LSTM이라고 합니다. 

LSTM은 은닉층의 메모리 셀에 << 입력 게이트, 망각 게이트, 출력 게이트를 추가하여 불필요한 기억을 지우고, 기억해야할 것들을 정합니다 >>. 

요약하면 LSTM은 은닉 상태(hidden state)를 계산하는 식이 전통적인 RNN보다 조금 더 복잡해졌으며 셀 상태(cell state)라는 값을 추가하였습니다. 

위의 그림에서는 t시점의 셀 상태를 $C_{t}$로 표현하고 있습니다. LSTM은 RNN과 비교하여 긴 시퀀스의 입력을 처리하는데 <<탁월한 성능>>을 보입니다.


![](https://static.wikidocs.net/images/page/22888/cellstate.PNG)

셀 상태는 위의 그림에서 왼쪽에서 오른쪽으로 가는 굵은 선입니다. 
셀 상태 또한 이전에 배운 은닉 상태처럼 이전 시점의 셀 상태가 다음 시점의 셀 상태를 구하기 위한 입력으로서 사용됩니다.

은닉 상태값과 셀 상태값을 구하기 위해서 새로 추가 된 3개의 게이트를 사용합니다. 각 게이트는 삭제 게이트, 입력 게이트, 출력 게이트라고 부르며 이 3개의 게이트에는 공통적으로 시그모이드 함수가 존재합니다. 

시그모이드 함수를 지나면 0과 1사이의 값이 나오게 되는데 이 값들을 가지고 게이트를 조절합니다. 아래의 내용을 먼저 이해하고 각 게이트에 대해서 알아보도록 하겠습니다.

- 이하 식에서 σ는 시그모이드 함수를 의미합니다.
- 이하 식에서 tanh는 하이퍼볼릭탄젠트 함수를 의미합니다.
- $W_{xi}, W_{xg}, W_{xf}, W_{xo}$는 $x_{t}$와 함께 << 각 게이트에서 사용되는 4개의 가중치입니다. >>  (여기서 f는 삭제게이트, g는 새로운 정보 후보군 = 기억할 핵심 내용의 내용물 자체를 만드는 것)
- $W_{hi}, W_{hg}, W_{hf}, W_{ho}$는 $h_{t-1}$와 함께 각 게이트에서 사용되는 4개의 가중치입니다.
- $b_{i}, b_{g}, b_{f}, b_{o}$는 각 게이트에서 사용되는 4개의 편향입니다.


왜 게이트는 3개인데 연산은 4개일까??

=> 입력 게이트(Input Gate) 연산이 **사실상 2개의 단계**로 나뉘어 진행되기 때문입니다!

새로운 정보를 장기 기억 메모리($C_t$)에 추가하려면 아래 두 과정이 필요합니다.

1. **"무슨 내용"을 저장할 것인가?** $\rightarrow$ **$g$** ($\tanh$ 연산으로 핵심 정보 후보 작성)

2. **"그 내용을 얼마나(몇 %)" 반영할 것인가?** $\rightarrow$ **$i$** ($\sigma$ 연산으로 $0 \sim 1$ 사이 문 크기 조절)

결국 이 둘을 곱해서($i \odot g$) 장기 기억에 더해주게 됩니다.

즉, **$i$와 $g$가 한 세트가 되어 '입력 게이트' 역할을 수행**하기 때문에, 연산 내부에는 **$i, g, f, o$ 총 4개의 가중치 행렬**이 존재하게 됩니다.





### 1) 입력 게이트

![](https://static.wikidocs.net/images/page/22888/inputgate.PNG)

$i_{t}=σ(W_{xi}x_{t}+W_{hi}h_{t-1}+b_{i})$  
$g_{t}=tanh(W_{xg}x_{t}+W_{hg}h_{t-1}+b_{g})$

입력 게이트는 << 현재 정보 >> 를 기억하기 위한 게이트입니다. 
우선 ( 현재 시점 t의 $x$값 ) 과 입력 게이트로 이어지는 가중치 $W_{xi}$를 곱한 값과 이전 시점 t-1의 은닉 상태가 입력 게이트로 이어지는 가중치 $W_{hi}$를 곱한 값을 더하여 시그모이드 함수를 지납니다. 이를 $i_{t}$라고 합니다.
(가중치표기이해 : $W_{xi}$ = 현재의 x를 i로 만드는 식의 가중치)

그리고 현재 시점 t의 $x$값과 입력 게이트로 이어지는 가중치 $W_{xi}$를 곱한 값과 이전 시점 t-1의 은닉 상태가 입력 게이트로 이어지는 가중치 $W_{hg}$를 곱한 값을 더하여 하이퍼볼릭탄젠트 함수를 지납니다. 이를 $g_{t}$라고 합니다.

시그모이드 함수를 지나 0과 1 사이의 값과 하이퍼볼릭탄젠트 함수를 지나 -1과 1사이의 값 두 개가 나오게 됩니다. 이 두 개의 값을 가지고 이번에 선택된 기억할 정보의 양을 정하는데, 구체적으로 어떻게 결정하는지는 아래에서 배우게 될 셀 상태 수식을 보면 됩니다.

=> 그래서 의미적으로 i와 g는 정확히 무엇인가?

### $g_t$와 $i_t$의 구체적인 역할

- **$g_t$ (새로운 정보의 내용 / 후보군):**
    
    - 말씀하신 "갱신할 기억 그 자체(내용물)"가 맞습니다!
        
    - 현재 들어온 입력($x_t$)과 이전 은닉 상태($h_{t-1}$)를 조합해서 "이번 타임스텝에서 새로 추가할 만한 지식/기억 메시지"를 직접 만들어냅니다.
        
    - $\tanh$를 쓰기 때문에 **긍정적인 정보는 양수(+), 부정적이거나 반대되는 정보는 음수(-)** 형태로 실제 정보의 가치와 내용이 담깁니다.

- **$i_t$ (입력 게이트의 수도꼭지 / 필터):**
    
    - $g_t$가 아무리 좋은 기억이라도, "지금 이 타이밍에 이걸 얼마나 반영할지(0~100%)"를 결정하는 **조절 밸브** 역할을 합니다.
        
    - Sigmoid를 쓰기 때문에 $0 \sim 1$ 사이의 비율(비중) 값을 가집니다.

### 두 값이 합쳐져서 일어나는 일 ($i_t \odot g_t$)

결국 셀 상태($C_t$)를 업데이트할 때는 이 두 값을 요소별 곱(Element-wise multiplication, $\odot$)합니다.

$$\text{새로 저장될 최종 기억} = i_t \odot g_t$$

- **예시:**
    
    - 만약 $g_t$ (새로운 기억 내용) = `[0.8, -0.5]` (아주 중요한 정보)
        
    - 만약 $i_t$ (문 열림 정도) = `[0.9, 0.0]` (첫 번째 요소는 90% 반영, 두 번째는 0% 반영)
    
    - **최종 반영되는 기억** = `[0.72, 0.0]`
    

### 💡 요약

- **$g_t$:** "무엇을 기억할 것인가?" $\rightarrow$ **실제 갱신될 기억 메시지 내용 그 자체**

- **$i_t$:** "그 기억을 얼마나 받아들일 것인가?" $\rightarrow$ **기억의 통과 비율(필터/밸브)**


일단 식 자체를 보면, 구조적으로 g라는애가 처음부터 분리되진 않고 특성상 같은 입력과 h로인해 갱신되는건데 
g는 역탄젠트, i는 시그모이드쓰면서 그 역할이 달라진다고 보면 됨. 특성이 쪼개지는 느낌으로.. 각각의 기능적의미를 이해한 후 사진을 보면 더 쉬움!




### 2) 삭제 게이트

![](https://static.wikidocs.net/images/page/22888/forgetgate.PNG)

$f_{t}=σ(W_{xf}x_{t}+W_{hf}h_{t-1}+b_{f})$

삭제 게이트는 기억을 삭제하기 위한 게이트입니다. 

현재 시점 t의 $x$값과 이전 시점 t-1의 은닉 상태가 시그모이드 함수를 지나게 됩니다. 시그모이드 함수를 지나면 0과 1 사이의 값이 나오게 되는데, 

이 값이 곧 삭제 과정을 거친 정보의 양입니다. 0에 가까울수록 정보가 많이 삭제된 것이고 1에 가까울수록 정보를 온전히 기억한 것입니다. 

이를 가지고 셀 상태를 구하게 되는데, 구체적으로는 아래의 셀 상태 수식을 보면 됩니다.

---

=> 입력게이트에서의 $\sigma$ 처럼 기억하는 값 비율을 조정하는데 그 범위가 셀 상태 자체 값(\== 이전값)에 대한 비율적 삭제인것.

삭제 게이트($f_t$, Forget Gate)의 핵심은 바로 **'과거의 장기 기억(이전 셀 상태 $C_{t-1}$)'을 얼마나 지우고 남아있게 할 것인가**입니다.

입력 게이트와 비교해서 셀 상태($C_t$) 수식 전체를 보면 이해가 단번에 되실 겁니다!

#### 1. 셀 상태($C_t$) 업데이트 수식으로 보는 차이

$$C_t = \underbrace{f_t \odot C_{t-1}}_{\text{삭제 게이트의 역할}} + \underbrace{i_t \odot g_t}_{\text{입력 게이트의 역할}}$$

##### 1) 삭제 게이트 파트 ($f_t \odot C_{t-1}$)

- **$C_{t-1}$**: 지난 타임스텝까지 쌓여온 **원래의 장기 기억(셀 상태 자체값)**
    
- **$f_t$**: 삭제 게이트가 내놓은 시그모이드 값 ($0 \sim 1$)
    
- **의미:** << 원래 갖고 있던 셀 상태 값 >> 에 $0 \sim 1$ 사이의 비율을 곱해서, **"이전 기억을 몇 % 남길지(또는 몇 % 삭제할지)"** 결정합니다.
    
    - $f_t = 1$ 이면 $\rightarrow$ 이전 기억 $100\%$ 보존 (삭제 안 함)
        
    - $f_t = 0$ 이면 $\rightarrow$ 이전 기억 $0\%$ (완전히 싹 삭제)
        

##### 2) 입력 게이트 파트 ($i_t \odot g_t$)

- "이번 시점($t$)에서 새로 들어온 정보 중 얼마를 보탤지"를 결정해서 뒤에 **더해(+)** 줍니다.
    

#### 💡 직관적인 비유 (노트 정리)

- **$C_{t-1}$ (이전 셀 상태):** 어제까지 노트에 적어둔 **기존 메모 내용**
    
- **$f_t$ (삭제 게이트):** **지우개** (기존 노트 내용 중 쓸모없어진 옛날 정보나 주어가 바뀐 부분을 지움)
    
- **$i_t \odot g_t$ (입력 게이트):** **볼펜** (오늘 새로! 들어온 정보 중 중요한 내용을 노트에 추가로 적음)




### 3) ==셀 상태(장기 상태)

![](https://static.wikidocs.net/images/page/22888/cellstate2.PNG)

$C_{t}=f_{t}∘C_{t-1}+i_{t}∘g_{t}$

셀 상태 $C_{t}$를 LSTM에서는 << 장기 상태 >> 라고 부르기도 합니다. 
=> 덧셈구조(옛기억 `*` 비율 + 현재기억 `*` 비율) 라서 아예 dot product해서 가중치를 갱신(뭉개기)하는 바닐라 RNN이랑은 다르게, 비율적으로, 이전 기억/ 현재 기억을 조절해서 훨씬 더 기억이 잘 보존되기 떄문 : 장기적 유지!
또한, 그래디언트가 역전파될때 첫 단어가 아예 소멸되지 않기 때문에 (비율+덧셈구조) 그래디언트 역산 시 첫 단어 정보가 남아있음.

은닉 상태($h_t$)는 그럼 왜 '단기 상태'일까?

- **$C_t$ (셀 상태 = 장기 상태):**
    
    - 밖으로 노출되지 않고 내부에서만 조용히 유지되는 **완전한 원본 장기 기억 메모리**

- **$h_t$ (은닉 상태 = 단기 상태):**
    
    - $C_t$에 $\tanh$를 씌우고 출력 게이트($o_t$)를 곱해서 **"당장 다음 시점($t+1$)이나 출력층으로 내보내기 위해 가공한 1회성/단기성 기억"**



그렇다면 셀 상태를 구하는 방법을 알아보겠습니다. 
삭제 게이트에서 일부 기억을 잃은 상태입니다.

입력 게이트에서 구한 $i_{t}$, $g_{t}$ 이 두 개의 값에 대해서 원소별 곱(entrywise product)을 진행합니다. 다시 말해 << 같은 크기의 두 행렬이 있을 때 같은 위치의 성분끼리 곱하는 것을 말합니다. >>  여기서는 식으로 ∘ 로 표현합니다. 이것이 이번에 선택된 기억할 값입니다.

입력 게이트에서 선택된 기억을 삭제 게이트의 결과값과 더합니다.
이 값을 현재 시점 t의 셀 상태라고 하며, << 이 값은 다음 t+1 시점의 LSTM 셀로 넘겨집니다. >> 

삭제 게이트와 입력 게이트의 영향력을 이해해봅시다. 
만약 삭제 게이트의 출력값인 $f_{t}$가 0이 된다면, 이전 시점의 셀 상태값인 $C_{t-1}$은 현재 시점의 셀 상태값을 결정하기 위한 영향력이 0이 되면서, 오직 입력 게이트의 결과만이 현재 시점의 셀 상태값 $C_{t}$을 결정할 수 있습니다. 이는 삭제 게이트가 완전히 닫히고 입력 게이트를 연 상태를 의미합니다. 

반대로 입력 게이트의 $i_{t}$값을 0이라고 한다면, 현재 시점의 셀 상태값 $C_{t}$는 오직 이전 시점의 셀 상태값 $C_{t-1}$의 값에만 의존합니다. 이는 입력 게이트를 완전히 닫고 삭제 게이트만을 연 상태를 의미합니다. 결과적으로 삭제 게이트는 이전 시점의 입력을 얼마나 반영할지를 의미하고, 입력 게이트는 현재 시점의 입력을 얼마나 반영할지를 결정합니다.

### 4) 출력 게이트와 은닉 상태(단기 상태)

![](https://static.wikidocs.net/images/page/22888/outputgateandhiddenstate.PNG)

$o_{t}=σ(W_{xo}x_{t}+W_{ho}h_{t-1}+b_{o})$  
$h_{t}=o_{t}∘tanh(c_{t})$

출력 게이트는 현재 시점 t의 $x$값과 이전 시점 t-1의 은닉 상태가 시그모이드 함수를 지난 값입니다. 해당 값은 현재 시점 t의 은닉 상태를 결정하는 일에 쓰이게 됩니다. 

<< 은닉 상태를 단기 상태라고 하기도 합니다. 은닉 상태는 장기 상태의 값이 하이퍼볼릭탄젠트 함수를 지나 -1과 1사이의 값입니다. 해당 값은 출력 게이트의 값과 연산되면서, 값이 걸러지는 효과가 발생합니다. 단기 상태의 값은 또한 출력층으로도 향합니다. >> 


입력게이트 : x랑 h로 가공하는 i랑 g 컨트롤 (i는 정도고, g는 입력으로부터 나온 새 기억 내용)

삭제게이트 : 현재 x랑 h를 어떻게 처리할지를 결정하여 셀 상태 갱신에 기여

현재시점 출력게이트 값 : 현재 시점의 x랑 h, 편향의 합이 시그모이드 거친 값

현재시점 은닉상태 : 현재 시점의 셀상태를 tanh 취한것 (값평탄화) *(원소자리곱) 출력게이트값


## 4. 파이토치의 nn.LSTM()

파이토치에서 LSTM 셀을 사용하는 방법은 매우 간단합니다. 
기존에 RNN 셀을 사용하려고 했을 때는 다음과 같이 사용했었습니다.

```python
nn.RNN(input_dim, hidden_size, batch_first=True)
```

LSTM 셀은 이와 유사하게 다음과 같이 사용합니다.

```python
nn.LSTM(input_dim, hidden_size ,batch_first=True)  
```



이제 LSTM의 대체재로 여겨지는 GRU(Gated Recurrent Unit)에 대해서 정리해봅시다. GRU는 2014년 뉴욕대학교 조경현 교수님이 집필한 논문에서 제안되었습니다. 

GRU는 LSTM의 장기 의존성 문제에 대한 해결책을 유지하면서, 
은닉 상태를 업데이트하는 계산을 줄였습니다. 

다시 말해서, GRU는 성능은 LSTM과 유사하면서 복잡했던 LSTM의 구조를 간단화 시켰습니다.

## 5. GRU(Gated Recurrent Unit)

LSTM에서는 출력, 입력, 삭제 게이트라는 3개의 게이트가 존재했습니다. 
반면, GRU에서는 업데이트 게이트와 리셋 게이트 두 가지 게이트만이 존재합니다. GRU는 LSTM보다 학습 속도가 빠르다고 알려져있지만 여러 평가에서 GRU는 LSTM과 비슷한 성능을 보인다고 알려져 있습니다.

![](https://static.wikidocs.net/images/page/22889/gru.PNG)

$r_{t}=σ(W_{xr}x_{t}+W_{hr}h_{t-1}+b_{r})$  
$z_{t}=σ(W_{xz}x_{t}+W_{hz}h_{t-1}+b_{z})$  
$g_{t}=tanh(W_{hg}(r_{t}∘h_{t-1})+W_{xg}x_{t}+b_{g})$  
$h_{t}=(1-z_{t})∘g_{t}+z_{t}∘h_{t-1}$

GRU와 LSTM 중 어떤 것이 모델의 성능면에서 더 낫다라고 단정지어 말할 수 없으며, << 기존에 LSTM을 사용하면서 최적의 하이퍼파라미터를 찾아낸 상황이라면 굳이 GRU로 바꿔서 사용할 필요는 없습니다. >>

경험적으로 << 데이터 양이 적을 때는 매개 변수의 양이 적은 GRU가 조금 더 낫고, 데이터 양이 더 많으면 LSTM이 더 낫다 >> 고도 합니다. GRU보다 LSTM에 대한 연구나 사용량이 더 많은데, 이는 LSTM이 더 먼저 나온 구조이기 때문입니다.

- **업데이트 게이트 ($z_t$):** 이전의 은닉 상태 $h_{t-1}$를 얼마나 유지하고, 새로운 정보 $\tilde{h}_t$를 얼마나 반영할지 한 번에 결정합니다.
    
- **리셋 게이트 ($r_t$):** 새로운 정보를 만들 때 이전 은닉 상태 $h_{t-1}$를 얼마나 지울지 결정합니다.

==> 트랜스포머(Transformer)와 어텐션(Attention) 알고리즘이 NLP와 생성형 AI 분야를 완벽히 지배한 것은 맞지만, **실무 및 특정 연구 분야에서는 여전히 LSTM과 GRU가 활발하게 쓰이고 있습니다.**

트랜스포머가 절대 왕좌를 차지했음에도 불구하고 왜 아직 순환 신경망(RNN 계열)이 생존해 있는지, 그 명확한 이유 세 가지를 정리해 드릴게요.

#### 1. 연산 오버헤드와 자원 제약 (Edge / Embedded Systems)

트랜스포머의 셀프 어텐션(Self-Attention) 연산은 입력 시퀀스 길이($N$)가 길어질수록 연산량과 메모리 사용량이 $O(N^2)$ (제곱)으로 폭증합니다.

- **스마트워치, 스마트폰, IoT 기기, 로봇:**
    
    - 메모리(RAM)가 몇 백 MB 단위이거나 배터리 효율이 극도로 중요한 온디바이스(On-device) 환경에서는 거대한 트랜스포머 모델을 돌리기 어렵습니다. => 이건 왜 SW적으로 백 서버 두고 서빙을 안 하고 기기 자체에 임베디드로 넣을까? : 지연시간, 실시간성, 네트워크 문제, 서버비용, 보안 등으로 인해 HW적 서빙을 선호한다고함 (모델 가중치(파라미터)가 칩 내부 SRAM/플래시에 저장되어서, 초저전력 DSP/NPU 칩=> 경량모델상시동작 => 호출어감지:빅스비,시리 등 시 메인CPU꺠움 이런 구조라고생각하면됨. 최근에는 더 경량화된 모델로 대체하긴 함.)

- **LSTM / GRU의 강점:**
    
    - 시퀀스 길이가 늘어나도 메모리와 연산량이 $O(N)$ (선형)으로 증가합니다.
    
    - 파라미터 크기가 매우 작아서 **초저전력·저메모리 환경에서 실시간(Real-time)으로 추론**하기에 훨씬 압도적입니다.
    

#### 2. 시계열 데이터(Time-Series) 및 센서 데이터 분석

자연어(NLP)는 트랜스포머가 평정했지만, **주가 예측, 공장 설비 센서 데이터, 심박수/EEG 생체 신호, 기상 데이터** 같은 1차원 시계열 분야에서는 여전히 LSTM과 GRU가 최전선에서 쓰입니다.

- **데이터 양의 한계:**
    
    - 공장 센서나 특정 환자의 데이터처럼 **데이터 수집량이 적은 도메인**에서는 데이터가 수십만~수백만 개 필요한 트랜스포머를 쓰면 극심한 오버피팅(Overfitting)이 발생합니다.

- **순차적 특성(Sequential Nature):**
    
    - 시계열 데이터는 과거부터 현재로 이어지는 **시간적 순서(Inductive Bias)** 자체가 매우 중요한데, << RNN 구조가 이러한 순차적 흐름을 학습하는 데 구조적으로 더 직관적이고 안정적 >> 입니다.



## 3. 실시간 스트리밍(Real-time Streaming) 데이터 처리

트랜스포머는 전체 문장/시퀀스를 한꺼번에 올려두고 계산하는 방식에 최적화되어 있습니다.

- **실시간 데이터 수신:**
    
    - 음성 인식(STT) 스트리밍이나 실시간 신호 처리처럼 **데이터가 밀리초(ms) 단위로 계속 들어오는 환경**에서는, 데이터를 받을 때마다 은닉 상태($h_t$)만 누적해서 업데이트하면 되는 LSTM/GRU가 훨씬 가볍고 빠릅니다.
    
- **트랜스포머의 한계:**
    
    - 트랜스포머로 실시간 처리를 하려면 매 순간 들어오는 새 데이터마다 전체 시퀀스의 어텐션 행렬을 다시 계산해야 하므로 과도한 연산 병목이 생깁니다. (오버헤드 큼 복잡도 N^2)

### 2) 모델 구현하기

이제 RNN 모델을 구현해봅시다. 
아래에서 fc는 완전 연결층(fully-connected layer)을 의미하며 
출력층으로 사용됩니다.

```python
class Net(torch.nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(Net, self).__init__()
        self.rnn = torch.nn.RNN(input_size, hidden_size, batch_first=True) # RNN 셀 구현
        self.fc = torch.nn.Linear(hidden_size, output_size, bias=True) # 출력층 구현

    def forward(self, x): # 구현한 RNN 셀과 출력층을 연결
        x, _status = self.rnn(x)
        x = self.fc(x)
        return x
```

클래스로 정의한 모델을 net에 저장합니다.

```python
net = Net(input_size, hidden_size, output_size)
```

```python
    result_str = ''.join([index_to_char[c] for c in np.squeeze(result)])
```

```ruby
class Net(torch.nn.Module):
```

# 용어 정리
## RNN 기억 소실 (hidden state), 기울기 소실 관계


은닉 상태($h_t$)의 기억이 타임스텝을 거듭하며 흐려지고 사라지는 현상과
**기울기 소실(Vanishing Gradient)** 문제는 서로 동전의 양면처럼 긴밀하게 연결되어 있습니다.

이 둘이 왜 같은 문제인지, 그리고 작성하신 말씀처럼 활성화 함수가 어떤 역할을 하는지 깔끔하게 정리해 드릴게요.

### 1. 역전파 때 기울기가 사라지면 무슨 일이 벌어질까?

RNN에서 $t=100$ 시점의 오차(Loss)를 가지고 $t=1$ 시점의 첫 단어 관련 가중치($W_h$)를 학습시키려면, 기울기(Gradient)가 시간을 거슬러 거슬러 $t=1$까지 전달되어야 합니다.

하지만 역전파(BPTT) 과정에서 타임스텝을 거슬러 올라갈 때마다 **가중치 $W_h$의 행렬곱**과 **활성화 함수의 미분값**이 계속 곱해집니다.

이때 기울기가 << 점점 작아져서 $t=1$ 근처에 도달했을 때는 **기울기가 $0$에 가까워져(기울기 소실)** 버립니다. >> 정보소실.

### 2. 기울기가 소실되면 왜 "기억을 잃는다"고 할까?

수학적으로 기울기가 $0$이 된다는 것은 "$t=1$ 시점의 입력 데이터가 $t=100$ 시점의 최종 출력 결과에 아무런 영향을 주지 못한다"는 뜻이 됩니다.

즉, 역전파 관점에서는 **기울기 소실**이지만, 순방향(Forward) 및 모델의 기억 관점에서는 "앞쪽 타임스텝의 단어(기억)를 까먹었다/소멸했다"라고 표현하는 것입니다. => 구조적 동일, 의미적인 추가정보가 붙었다고 이해하면 될듯
사실 RNN은 h라는 은닉층의 시간적:데이터길이/시퀀스적인 제3의가중치를 추가한 SLP니까 (DRNN는 같은느낌으로MLP 대응하고)

### 3. 짚어주신 활성화 함수($\tanh$, $\sigma$)의 문제점

지적하신 내용이 완벽히 맞습니다!

- **시그모이드($\sigma$) 미분값:** 최대값이 $0.25$입니다.
    
    - 10번만 거슬러 올라가도 $0.25^{10} \approx 0.00000095$가 되어 기울기 소실이 극심해집니다.
        
- **하이퍼볼릭 탄젠트($\tanh$) 미분값:** 최대값이 $1.0$이지만, 양끝으로 갈수록 미분값이 $0$에 수렴합니다.
    
    - 결국 타임스텝이 조금만 길어져도 미분값들이 $1$보다 작아져 계속 곱해지면서 기울기를 $0$으로 만들어 버립니다.
        

### 💡 결론

> **"앞쪽 타임스텝의 기억이 지워지는 현상은 역전파 시 $\tanh$나 $\sigma$의 미분값과 가중치가 반복 곱해져 기울기가 $0$으로 소멸하기(기울기 소실) 때문에 발생하는 현상이 맞습니다!"**




## LSTM 은 단어 첫 정보를 역추적 가능한가?

결론부터 말씀드리면, **역전파(Backpropagation) 과정이나 저장된 그래프 데이터를 이용해도 "입력되었던 맨 첫 단어(원본 데이터)"를 완벽하게 역추출하는 것은 불가능합니다.**

생각하신 이유가 완벽하게 맞습니다! 편미분의 불가역성(정보 손실)과 **활성화 함수의 정보 찌그러뜨림** 때문입니다.

왜 역추출이 불가능한지, 질문자님이 아주 정확하게 짚어주신 수학적/구조적 이유를 바탕으로 정리해 드릴게요.

### 1. 적분상수 문제와 정보의 손실 (다대일 매핑)

질문자님께서 "편미분은 적분으로 되돌릴 수 없다(적분상수 문제)"라고 말씀하신 점이 핵심입니다.

- **손실(Loss)을 미분한다는 것:**
    
    역전파에서 저장하는 그래프 기록(Autograd)은 "기울기(Gradient, $\frac{\partial L}{\partial W}$)"입니다.
    
- **기울기의 한계:**
    
    기울기는 "어느 방향으로 얼마큼 가중치를 조절해야 하는가"에 대한 **변화율 정보**일 뿐입니다.
    
- **정보의 일대다(1-to-Many) 관계:**
    
    $$y = x_1 + x_2$$
    
    위와 같은 단순한 덧셈만 해도 $y=5$라는 결과를 얻었을 때 원본 $x_1, x_2$가 $(2, 3)$이었는지 $(1, 4)$였는지 역추적할 수 없습니다. 수많은 입력값이 하나의 출력값으로 압축(손실)되었기 때문에 **원래의 입력 텐서를 고유하게 복원할 수가 없습니다.**
    

### 2. 비선형 활성화 함수($\sigma, \tanh$)의 상쇄 효과

LSTM 내부에서는 $\tanh$와 시그모이드($\sigma$)를 계속 통과합니다.

- 입력값 범위가 아무리 크거나 다양했어도 $\tanh$를 지나면 모든 값이 **$-1 \sim 1$ 사이**로 찌그러집니다.
    
- 여러 수식과 게이트를 거치는 과정에서 수학적인 정보 상쇄(Information Loss)가 발생하기 때문에, 계산된 기울기나 내부 상태값만 보고 "처음 입력된 단어의 엠베딩 벡터"를 완전하게 역산해내는 공식은 존재하지 않습니다.
    

### 3. "자동미분(Autograd) 계산 그래프"로 안 되는 이유?

PyTorch 등의 자동미분기(Autograd)가 연산 그래프(Computational Graph)를 메모리에 기억해 두는 것은 맞습니다.

하지만 계산 그래프가 기억하는 것은:

> *"역전파할 때 체인 룰(Chain Rule)을 적용하기 위해 **중간 연산 결과(기울기 계산용)** 를 임시 보관"* 하는 것이지, **연산 자체를 역함수(Inverse Function)처럼 거꾸로 실행해 주는 기능이 아닙니다.**

### 💡 요약 및 직관적인 비유

- **LSTM이 기억을 보존한다는 의미:**
    
    첫 단어라는 **원본 텍스트 자체를 100% 복원할 수 있게 들고 있다는 뜻이 아니라**, 그 단어가 가진 **'맥락적 의미(기억의 흔적)'가 손실되지 않고 최종 판단에 영향을 줄 수 있다**는 뜻입니다.
    
- **믹서기 비유:**
    
    사과, 바나나, 딸기를 넣고 쥬스를 만들었습니다.
    
    - **RNN:** 믹서기를 너무 세게 돌려 딸기 맛이 아예 안 남음 (기억 소실).
        
    - **LSTM:** 비율 조절을 잘 해서 쥬스를 다 마실 때까지 딸기 향이 느껴짐 (장기 기억 유지).
        
    - **역추출:** 쥬스 상태와 믹서기 조작 기록(그래프)을 가지고 갈려버린 원래 딸기 형체를 완벽하게 부활시키는 것(역추출)은 불가능함.
        

따라서 "기울기가 소멸하지 않아 첫 단어의 '영향력(기억)'은 뒤까지 전달되지만, 미분과 연산의 불가역성 때문에 첫 단어 '원본'을 역추출하는 것은 불가능하다"가 정답입니다.





## 파이썬 컴프리헨션 문법 복습

### List Comprehension `[]`

```python
# 기본
[x for x in range(5)]
# [0, 1, 2, 3, 4]

# 조건
[x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# 변환
[x**2 for x in range(5)]
# [0, 1, 4, 9, 16]
```

---

### Dict Comprehension `{}`

```python
# 기본
{k: v for k, v in enumerate(['a', 'b', 'c'])}
# {0: 'a', 1: 'b', 2: 'c'}

# key/value 뒤집기
d = {'a': 1, 'b': 2}
{v: k for k, v in d.items()}
# {1: 'a', 2: 'b'}
```

---

### Set Comprehension `{}`

```python
{x % 3 for x in range(10)}
# {0, 1, 2}  중복 제거
```

---

### Generator Expression `()`

```python
# 리스트랑 비슷한데 메모리 안 씀
gen = (x**2 for x in range(5))
next(gen)  # 0
next(gen)  # 1
```

---

### 중첩

```python
# 2D 리스트 펼치기
matrix = [[1,2],[3,4],[5,6]]
[x for row in matrix for x in row]
# [1, 2, 3, 4, 5, 6]
```

## RNN 내부 구현체 미리보기


```python
class RNN(RNNBase):
    def __init__(self, input_size, hidden_size, ...):
        super().__init__('RNN', input_size, hidden_size, ...)
```

`RNNBase`가 실제 무거운 일을 다 해요. RNN은 그냥 mode='RNN'으로 특정해서 넘기는 껍데기예요.

---

### RNNBase 핵심 구조

```python
class RNNBase(nn.Module):
    def __init__(self, mode, input_size, hidden_size, ...):
        
        # 가중치 초기화
        # Wx: input → hidden
        # Wh: hidden → hidden
        self.weight_ih_l0  # (hidden_size, input_size)
        self.weight_hh_l0  # (hidden_size, hidden_size)
        self.bias_ih_l0
        self.bias_hh_l0

    def forward(self, input, hx=None):
        # hx 없으면 0으로 초기화
        if hx is None:
            hx = torch.zeros(...)

        # 실제 연산은 C++ 백엔드로 넘김
        result = _VF.rnn_tanh(input, hx, self._flat_weights, ...)
        
        output, hidden = result
        return output, hidden
```

---

### 핵심 포인트

**`_VF.rnn_tanh`** — 여기서 실제 타임스텝 루프가 돌아요. 
Python이 아니라 **C++ ATen 커널**로 구현돼있어요. 
GPU면 CUDA 커널로 넘어가요.

```
Python RNN.forward()
    ↓
C++ _VF.rnn_tanh()
    ↓
for t in seq_len:
    h_t = tanh(x_t @ Wx + h_(t-1) @ Wh + b)
    ↓
CUDA 커널 (GPU면)
```

---

### 가중치 이름 구조

```python
rnn.weight_ih_l0  # input-hidden, layer 0
rnn.weight_hh_l0  # hidden-hidden, layer 0
rnn.bias_ih_l0
rnn.bias_hh_l0

# 2층이면
rnn.weight_ih_l1  # layer 1
rnn.weight_hh_l1
```

`l0`, `l1`이 레이어 번호예요. `num_layers=2`면 두 세트가 생겨요.
