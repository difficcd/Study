# 프롬프트 캐싱 (Prompt Caching)

[[README|← Claude 활용법]] · [[Claude Code 동작 방식]]에서 이어짐

> [[Claude Code 동작 방식]]에서 봤듯 모델은 무상태라 **매 호출마다 대화 전체를 재전송**한다.
> 그 반복되는 앞부분을 서버가 캐시해두고 재사용하는 게 프롬프트 캐싱 — 비용과 지연을 크게 줄인다.
> Claude Code가 긴 세션에서도 빠르고 싸게 도는 핵심 이유.

## 1. 단 하나의 불변 원칙

**캐싱은 "접두사(prefix) 일치"다. 접두사 어딘가의 1바이트만 바뀌어도 그 뒤 전부 무효화된다.**

- 렌더 순서: `tools` → `system` → `messages`. 이 순서대로 바이트가 이어붙고,
  `cache_control` 표시 지점까지의 바이트가 캐시 키가 된다.
- 그래서 설계 원칙은 하나: **안 변하는 것을 앞에, 자주 변하는 것을 뒤에.**
  - 고정: 시스템 프롬프트(동결), 도구 목록(결정적 순서) → 앞
  - 매 요청 변하는 것: 타임스탬프, 요청 ID, 이번 질문 → 마지막 브레이크포인트 뒤

## 2. 사용법

```python
response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=16000,
    system=[{
        "type": "text",
        "text": "<크고 고정된 시스템 프롬프트>",
        "cache_control": {"type": "ephemeral"},   # ← 여기까지 캐시 (5분 TTL)
        # {"type": "ephemeral", "ttl": "1h"}      # 1시간 TTL 옵션
    }],
    messages=[{"role": "user", "content": "이번 질문"}],  # 변하는 부분은 뒤
)
```

- 브레이크포인트는 요청당 **최대 4개**. system 마지막 블록에 걸면 tools+system이 같이 캐시됨.
- **멀티턴 대화**: 마지막으로 추가된 턴의 마지막 블록에 걸기 → 다음 요청이 직전 대화 전체를 재사용.
- 최소 캐시 길이(모델별 1024~4096 토큰) 미만이면 **조용히 캐시 안 됨** (에러 없음).

## 3. 경제성

| 구분 | 비용 (기본 입력가 대비) |
|---|---|
| 캐시 **읽기** | ~0.1× |
| 캐시 **쓰기** (5분 TTL) | 1.25× |
| 캐시 **쓰기** (1시간 TTL) | 2× |

→ 5분 TTL은 2번째 요청부터 이득, 1시간 TTL은 3번 이상 읽어야 본전.
같은 접두사를 여러 번 쓸수록 이득이 커진다 (에이전트 루프가 대표 사례 — 매 turn이 재사용).

## 4. 캐시를 조용히 깨는 것들 (silent invalidators)

| 패턴 | 왜 깨지나 |
|---|---|
| 시스템 프롬프트에 `datetime.now()` / 현재 날짜 삽입 | 매 요청 접두사가 다름 |
| UUID·요청 ID를 앞부분에 삽입 | 동일 |
| `json.dumps()`에 `sort_keys` 없이 직렬화 | 키 순서가 비결정적 → 바이트 다름 |
| 도구 목록을 중간에 추가/제거/재정렬 | tools는 위치 0 → 전체 무효화 |
| 모델 변경 | 캐시는 모델별로 분리됨 |

**검증법**: 응답의 `usage.cache_read_input_tokens`가 반복 요청에도 0이면 위 목록 중 뭔가가 범인.
(`cache_creation_input_tokens` = 이번에 캐시에 쓴 양, `input_tokens` = 캐시 안 된 나머지)

## 5. Claude Code와의 연결

- Claude Code의 시스템 프롬프트·CLAUDE.md·스킬 목록이 "고정 접두사", 대화가 뒤에 쌓이는 구조
  — 캐싱에 최적화된 형태라서 긴 세션도 매 turn 싸게 돈다.
- 에이전트 설계 시 응용: 모드 전환이 필요하면 시스템 프롬프트를 고치지 말고
  **메시지 뒤에 추가**(최신 모델은 `role: "system"` 메시지를 messages 배열에 넣는 것도 지원) —
  캐시된 접두사를 보존하는 방향으로.
