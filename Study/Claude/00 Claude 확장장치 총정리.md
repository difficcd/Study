# Claude 확장장치 총정리 — "쓰기"에서 "설계하기"로

> Claude Code를 챗봇처럼 *쓰는* 층 위에, 반복을 자동화·재사용 가능하게 *만드는* **레버리지 층**이 있다. 이 노트는 그 장치들 지도.
> 관련: [[04 MCP]] · [[03 Agent SDK]] · [[02 프롬프트 캐싱]] · [[01 Claude Code 동작 방식]]
> ※ 세부 문법은 버전따라 바뀜 — 확실치 않으면 `/help`나 공식 docs(docs.claude.com/claude-code) 확인. 아래는 개념+최소예시.

> 쓸 곳 : easy mv maker 증강하면서 (편집기능 강화 + 해상도 늘리기(중요, 완성도.) + 그림 추가할 수 있도록 해서 편집앱 정체성도 늘리기 + 장면전환 및 텍스트 움직임 보강하기 등..)

## 0. 한눈 지도 (뭘 언제)
| 장치                 | 한 줄                             | 만드는 곳                            | 난이도 | 언제                         |
| ------------------ | ------------------------------- | -------------------------------- | --- | -------------------------- |
| **슬래시 명령어**        | 반복 프롬프트를 한 단어로                  | `.claude/commands/*.md`          | ★   | 같은 지시를 자주 반복할 때            |
| **스킬(Skill)**      | 조건 맞으면 Claude가 *알아서* 꺼내 쓰는 능력 팩 | `.claude/skills/<name>/SKILL.md` | ★★  | "이런 상황이면 이렇게 해라"를 상시 주입    |
| **서브에이전트**         | 별도 문맥·도구·모델을 가진 전문 일꾼           | `.claude/agents/*.md`            | ★★  | 큰 작업을 격리/병렬로 위임            |
| **훅(Hook)**        | 특정 이벤트에 셸 명령 자동 실행              | `settings.json`                  | ★★★ | 강제/자동화(테스트·커밋·차단)          |
| **메모리(CLAUDE.md)** | 프로젝트 상시 컨텍스트                    | 프로젝트 루트 `CLAUDE.md`              | ★   | 프로젝트 규칙을 매 세션 주입           |
| **MCP**            | 외부 도구·데이터를 Claude에 연결           | `claude mcp add` / `.mcp.json`   | ★★★ | 내 앱·DB·API를 물릴 때 → [[04 MCP]] |

핵심 구분: **명령어=내가 부름 / 스킬·훅=조건 맞으면 자동 / 서브에이전트=위임 / MCP=바깥 연결.**

## 1. 슬래시 명령어 (제일 쉬움, 여기서 시작)

**정의**: `.claude/commands/이름.md` 파일 = `/이름` 명령. 파일 내용이 곧 프롬프트. `$ARGUMENTS`·`$1`·`$2`로 인자, 프론트매터로 옵션.

**최소 예시** — `.claude/commands/백지검토.md`:
```markdown
---
description: 내 코드에서 AI 없이 백지에서 못 짤 부분 진단
argument-hint: [파일경로]
allowed-tools: Read, Grep
---
@$1 을 읽고, 내가 이 코드를 백지에서 다시 짠다면 막힐 지점만 개념별로 짚어줘.
대신 짜주지 말고, 어디를 공부해야 하는지만.
```
→ 이제 `/백지검토 src/parser.py` 하면 실행. (`@`=파일첨부, `!`앞붙이면 셸명령 결과 삽입.)

**내 프로젝트용 3개**: `/백지검토`(from-scratch 약점 진단), `/소화`(세컨드브레인 인박스 소화 루프), `/학습로그`(오늘 공부→커밋메시지+요약).

---

## 2. 스킬 (Skill) — 조건부 자동 능력

**정의**: `.claude/skills/<이름>/SKILL.md`. 프론트매터의 `description`을 보고 **Claude가 상황에 맞으면 스스로 꺼내 씀**(내가 안 불러도). 스크립트·참고파일 동봉 가능(progressive disclosure = 필요할 때만 로드).

**최소 예시** — `.claude/skills/from-scratch-tutor/SKILL.md`:
```markdown
---
name: from-scratch-tutor
description: 사용자가 코딩 연습 중일 때 쓴다. 코드를 대신 작성하지 않고 힌트·검증·개념설명만 제공하는 튜터 모드.
---
규칙:
- 완성 코드를 절대 주지 않는다. 사용자가 직접 치게 한다.
- 막히면 다음 한 걸음의 힌트만. 답은 사용자가 도달하게.
- 사용자가 짠 걸 받으면 버그·개념오해만 짚는다.
```
→ 컴파일러 만들 때 이거 있으면 "너가 백지, 나는 검증"이 강제됨. **슬래시명령어=매번 호출 / 스킬=조건 맞으면 상시 발동**이 차이.

---

## 3. 서브에이전트 — 격리된 전문 일꾼

**정의**: `.claude/agents/이름.md`. 자기만의 시스템프롬프트·도구·모델·**별도 문맥창**을 가짐. 큰 작업을 위임하면 메인 대화 오염 없이 결과만 받음(여러 개 병렬 가능).

**최소 예시** — `.claude/agents/test-writer.md`:
```markdown
---
name: test-writer
description: 주어진 함수/모듈에 대한 단위테스트 작성 전문
tools: Read, Write, Bash
model: sonnet
---
너는 테스트 작성 전문가다. 대상 코드를 읽고 엣지케이스 포함 테스트를 작성·실행하고 결과만 보고한다.
```
→ 컴파일러 각 단계(lexer/parser/eval) 테스트를 얘한테 위임. 리서치·리뷰도 각각 에이전트로.

---

## 4. 훅(Hook) — 이벤트 자동화 (강제력)

**정의**: `settings.json`의 `hooks`에 등록. 특정 이벤트에 **셸 명령을 자동 실행**. 도구 호출을 막거나(차단) 후처리 가능.
**주요 이벤트**: `PreToolUse`(도구 실행 전, 차단 가능) · `PostToolUse`(후) · `UserPromptSubmit` · `Stop`(응답 끝) · `SessionStart` · `PreCompact`.

**최소 예시** — 파일 수정 뒤 자동 포맷 (`~/.claude/settings.json`):
```json
{
  "hooks": {
    "PostToolUse": [
      { "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "npx prettier --write \"$CLAUDE_FILE_PATHS\"" }] }
    ]
  }
}
```
→ 활용: 커밋 자동화, 저장 시 테스트 자동실행, 특정 파일 수정 차단. **가장 강력하지만 위험도 높음**(자동 실행이라) → 마지막에 배우기.

---

## 5. 메모리 (CLAUDE.md) — 프로젝트 상시 컨텍스트

**정의**: 프로젝트 루트의 `CLAUDE.md`는 매 세션 자동 로드. 프로젝트 규칙·구조·컨벤션을 적어두면 Claude가 항상 참고. `~/.claude/CLAUDE.md`=전역(모든 프로젝트). 대화 중 `#`으로 즉석 추가.
→ 컴파일러 repo에 `CLAUDE.md` 하나 두고 "이 프로젝트는 Crafting Interpreters 경로, 내가 직접 짜고 너는 검증만" 박아두면 매번 설명 안 해도 됨.

---

## 6. 기타 (알아두면 좋은 것)

- **플랜 모드**: 큰 작업 전 Claude가 계획만 먼저 세우고 승인받게 함(shift+tab). 착수 전 설계 확인용.
- **`claude -p "..."` (헤드리스)**: 대화 안 열고 스크립트/CI에서 Claude 실행. 자동화 파이프라인에 낌.
- **출력 스타일 / thinking**: 응답 톤 조정, `think`~`ultrathink`로 추론 깊이 요청.
- **프롬프트 캐싱**: 반복 컨텍스트 재사용해 비용·속도 절감 → [[02 프롬프트 캐싱]].
- **[[03 Agent SDK]]**: 위 개념들을 코드로 직접 조립해 **내 에이전트를 프로그램으로** 만드는 것. 최종 단계.

## 7. 추천 순서
현재 상태(실측): skills 1 / agents 0 / hooks 0 / commands 0 / MCP=playwright 1. **레버리지 층이 비어 있음.** 패턴은 코딩과 동일 — 공부는 했는데 안 만듦. 처방: **하나씩 실제로 만들기.**

1. **슬래시 명령어 1개** (`/백지검토`) — 오늘. commands 0 탈출 + from-scratch 도구 확보.
2. **스킬 1개** (from-scratch-tutor) — 컴파일러 착수 전. 백지 코딩 강제됨.
3. **서브에이전트 1개** (test-writer) — 컴파일러 진행 중 실사용.
4. **커스텀 MCP 1개** — Study 볼트나 MANAGE 데이터를 물리는 작은 서버. **이게 일석삼조**: Claude 유저→빌더 승격 + from-scratch 코딩 + AI 포트폴리오 + [[03 Agent SDK]] 노트 실전화.
5. **훅** — 마지막. 자동화 강제력 필요할 때(위험도 높으니 익숙해진 뒤).

> 원칙: 각 단계 **"읽기"가 아니라 "돌아가는 거 1개 만들기"**로 통과. 그게 이 노트의 목적이자 내 최대 gap(공부>빌드)을 닫는 법.
