
1. 4코어 4스레드 = 최대 4스레드?

  네, 맞습니다. 이 CPU가 동시에 처리할 수 있는 작업 흐름이 물리적으로 딱 4개. 하이퍼스레딩(코어당 2스레드)이 없어서
  4코어=4스레드가 최대치예요. 요즘 CPU가 "6코어 12스레드"처럼 두 배씩 가는 것과 달리, 이건 4가 천장입니다.

  2. RAM 슬롯

  정확히 이해하셨어요. 이 조립 PC 메인보드(Gigabyte H110M-DS2V)에 램 꽂는 자리가 2개인데, 지금 삼성 8GB 1개만 꽂혀
  있고 1개는 비어 있음. 그래서 8GB 하나 더 사서 꽂으면 →16GB가 되고, 덤으로 듀얼채널이 되면서 램 대역폭도 2배로
  빨라집니다 (지금은 싱글채널). 이게 이 PC 가성비 업글 1순위예요.

  3. GPU (참고: 실제로는 GTX 1050, 1080 아님)

  ⚠️먼저 정정: 아까 조사 결과 이 PC 그래픽카드는 GTX 1050 2GB입니다. 1080이 아니에요. (혹시 1080으로 바꾸셨거나 착각하신 거면 확인해 주세요)

  "있으나 없으나 똑같다"는 아닙니다 — 역할이 달라요.
  - CPU와 GPU는 하는 일이 다릅니다. GPU가 CPU 연산을 "대신"해주진 않아요. 다만 특정 작업(그래픽 렌더링, 영상 디코딩,
  게임)은 GPU가 전담합니다.
  - GTX 1050이 있으면: 유튜브 4K 영상 재생, 게임, SAI 화면 그리기 등을 GPU가 처리 →CPU 부담이 줄어요. 이건 확실히
  도움 됩니다.
  - 다만 "GPU가 CPU 스레드 부족을 메꿔준다"는 건 아니에요. 일반 프로그램 로직 처리는 여전히 CPU 몫.
  - 결론: 없는 것보단 훨씬 낫지만, 이 PC의 병목은 GPU가 아니라 RAM/CPU라서 GPU 업글은 우선순위 아님.

  4. C: SSD 필수인가? HDD가 좋아서 빠른 건가?

  - OS(운영체제)는 반드시 SSD에 있어야 쾌적합니다. 지금 C:가 SSD라서 부팅·프로그램실행이 그나마 빠른 거예요.
  - F: HDD로 옮기는 게 안 느린 이유는 HDD가 좋아서가 아닙니다. 파일 "복사/이동"은 순차 읽기·쓰기라HDD도 100~150MB/s
  나와서 그럭저럭 빠릅니다. HDD가 진짜 느려지는 건 OS나 프로그램처럼 작은 파일 수천 개를 랜덤하게 읽을 때 — 이때
  SSD가 10~100배 빨라요.
  - 이 WD Blue 1TB는 평범한 7200rpm HDD, 딱 창고용으로 정상 제품입니다. OS를 F:에 깔면 지금보다 훨씬 느려집니다. OS는
  C: SSD 유지가 정답.

  5. OS 바꾸는 과정 (대강)

  6. 백업 → C: 전체를 F:에 이미지로 저장 (Clonezilla 또는 Windows 시스템 이미지)
  7. 설치 USB → 우분투/아치 ISO 다운 → Rufus로 USB에 굽기 (USB 8GB+ 필요)
  8. USB 부팅    →     재부팅 →     BIOS에서 USB로 부팅 (F12 등 부팅메뉴)
  9. 라이브 체험 →  설치 없이 "체험하기"로 하드웨어 잘 되나 먼저 테스트
  10. 설치 → C: SSD를 지정해서 설치 (F: HDD는 절대 건드리지 않게 수동 파티션)
		(SSD 이중백업필수 : USB to C 로 연결 가능한지 확인만 하고 나서 ㄱㄱ)
  11. 드라이버 →  NVIDIA 드라이버 설치, 한글 입력기(fcitx) 설정
  12. 윈도우 + 리눅스 둘 다 선택 가능? (SAI 때문에)

  가능합니다! 이걸 "듀얼부팅"이라고 해요. ⭐ 당신 상황엔 이게 정답일 수 있어요.
  - C: SSD를 둘로 나눠서 →한쪽 Windows(SAI용), 한쪽 리눅스
  - 부팅할 때마다 "Windows로 갈래? 리눅스로 갈래?" 메뉴가 뜸
  - 다만 C:가 120GB라 둘로 쪼개면 각각 60GB로 좀 빡빡해요. SAI+Windows만 남기고 최소화하면 가능은 함.
  - 대안: 리눅스를 메인으로 깔고, SAI는 리눅스 안에서 Wine이나 가상머신으로 돌리는 방법. (타블렛 필압이 관건) => 이건 좀 보수적으로 잡아야할듯

  7. 아치리눅스에 오픈소스 UI "빼와서 박아버리기"

  개념적으로 정확히 맞습니다. 그게 아치의 철학이에요. 😄
  - 아치는 깡통(터미널만 있는 최소 상태)으로 시작 →  여기에 원하는 UI(데스크톱 환경)를 직접 골라 설치합니다.
  - 예: GNOME, KDE Plasma, XFCE, 또는 타일링 WM(Hyprland, i3, sway) 같은 걸 pacman -S로 가져와 박으면 됨.
  - "허구한날 UI 만드는 양반들 오픈소스" = 맞아요, KDE·GNOME·Hyprlan다 오픈소스라 그냥 설치하면 됩니다.
  - 단, 아치는 그 조립을 전부 수동으로 해야 해서 첫 리눅스 공부용으론 빡셉니다. 우분투 써보셨으니 다음 단계로 도전할만은 한데, 본체에 바로 깔기보단 우분투 위 가상머신에서 아치 연습 →익숙해지면 실전 추천.

  8. OS가 깔리는 "base"는 어디?

  - C: SSD에 깔립니다. OS는 부팅 드라이브(=C:, 여기선 120GB SSD)에 설치돼요.
  - 정확히는 SSD 안에 파티션(구획)을 만들고 거기에 시스템 파일이 들어갑니다. 리눅스는 /(루트)라는 곳에 깔려요 — Windows의 C:\에 해당.

  8. OS 바꾸면 F:는 안전한가?
  - 거의 안전하지만, "자동은 아님". 설치할 때 반드시 C:(Disk 0, SSD)만 골라서 설치하고 F:(Disk 1, HDD)는 건드리지 않게 해야 해요.
  - 리눅스 설치 화면에서 "디스크 전체 지우고 설치"를 무심코 누르면 위험하니, 수동 파티션에서 Disk 0(120GB SSD)만 선택하는 게 핵심.
  - F:는 NTFS 포맷이라 리눅스에서도 읽고 쓸 수 있어요. draw 폴더, 카톡 받은 파일 등 그대로 사용 가능.
  - ⭐ 그래서 백업 이미지도 F:에 저장하는 거고, 만약 F:에 백업 두고 F:를 실수로 밀면 백업까지 날아가니 — 정말 중요한 건 외장하드나 USB에 한 번 더 두는 게 안전.
