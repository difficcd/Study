### 1 RAM 못 꽂으면 노트북 VM에서 아치? — 네, 합리적입니다

  노트북에 우분투 VM 있고 40GB 여유면 아치 VM 추가는 충분해요. 그리고 VM 아치도 자격증·학습 목적의 90%는 커버합니다:  
  
  ✅ 배우는 것: 패키지 관리(pacman), systemd, 셸, 설정파일, 권한, 사용자관리 — 리눅스마스터 2급 내용 대부분
  
 ❌ VM에서 못 배우는 10%: 실제 부트로더·하드웨어 드라이버·파티션을 맨손으로 만지는 경험

  근데 그 10%는 어차피 데스크톱을 듀얼부팅하면서 자연히 배우게 돼요. 그러니 결론은:

  > 노트북 VM = 안전한 실험실 (막 부숴도 됨) + 데스크톱 듀얼부팅 
    = 진짜 베어메탈 경험. RAM 안 사도 이 조합으로 완성됩니다.

### 2 "유튜브+SAI만 쓰긴 아깝다" — 정확한 직감입니다 👏

  이 데스크톱, 재활용 가치가 꽤 높은 스펙이에요. 특히:
  - 1TB HDD = 파일/미디어 저장 창고로 완벽
  - GTX 1050 = 사실 하드웨어 영상 인코딩(NVENC) 가능 →미디어 서버 트랜스코딩에 딱
  - 항상 켜둘 수 있는 본체 = 서버 후보

  즉 이 PC를 **"홈 서버 겸 리눅스 실습장"** 으로 만들면, 
  재활용 + 자격증 공부 + 실사용을 한 번에 잡아요. 아이디어를

  💡 8GB RAM에서도 되는 이유

  서버는 GUI가 없어서(헤드리스) 램을 거의 안 먹고, Docker 컨테이너는 VM과 달리 커널을 공유해서 8GB로도
  Jellyfin+Nextcloud+Pi-hole 정도는 넉넉히 굴러갑니다. 램 구매 압박이 여기선 훨씬 덜해요.

  ⚖️단, 하나 정할 게 있어요

  "그림 그리는 작업용" vs "항상 켜두는 서버"는 살짝 충돌합니다 (서버는 24시간 켜두고, 드로잉은 앞에 앉아 쓰는 거라).
  세 가지 방향:

  1. 드로잉 우선: 리눅스 본체 + SAI(듀얼부팅) + 켜져 있을 때만 Docker로 홈랩 맛보기 →재활용감 + 그림 둘 다
  2. 서버 우선: 데스크톱을 헤드리스 홈 서버로 헌납, 그림은 노트북/다른 데서 →재활용 극대화지만 SAI 자리 잃음
  3. 하이브리드: 평소 리눅스 워크스테이션으로 쓰다가 관심 생기면 서버 비중 늘리기 (제일 무난)

  당신은 그림(SAI+타블렛)이 데스크톱에 묶여 있으니 저는 **1번(드로잉 우선 + 홈랩 겸용)** 을 추천해요. 리눅스 본체에서 Docker로 Jellyfin 하나 띄워보는 것부터 시작하면, "유튜브 머신"이 "내 미디어 서버 + 리눅스 실습장"으로 승격됩니다.
